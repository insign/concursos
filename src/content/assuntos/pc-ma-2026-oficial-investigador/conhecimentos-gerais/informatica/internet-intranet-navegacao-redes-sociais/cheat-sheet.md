# Revisão rápida — Internet, intranet, navegação, busca e redes sociais

## 1. As seis fronteiras que mais caem

| Conceito | Núcleo |
| --- | --- |
| **Internet** | infraestrutura global que interliga redes |
| **Web** | recursos interligados acessados por tecnologias web; é serviço sobre a Internet, não sinônimo dela |
| **Intranet** | ambiente/rede interna de acesso restrito que pode usar as mesmas tecnologias da Internet |
| **Navegador** | programa que solicita, interpreta e apresenta recursos da Web |
| **Mecanismo de busca** | serviço que rastreia, indexa e recupera/ordena resultados |
| **Rede social** | plataforma de perfis/contas, relações, publicação e interação |

**Pegadinhas:** navegador ≠ busca; Internet ≠ Web; intranet ≠ isolamento físico absoluto.

## 2. Anatomia de uma <abbr title="Uniform Resource Locator, localizador uniforme de recursos">URL</abbr>

Exemplo hipotético:

`https://portal.exemplo.gov.br/servicos/boletim?ano=2026#anexos`

- `https` → esquema;
- `portal.exemplo.gov.br` → host;
- `/servicos/boletim` → caminho;
- `?ano=2026` → consulta;
- `#anexos` → fragmento.

Pode haver porta explícita; nem todo componente aparece em toda <abbr title="Uniform Resource Locator, localizador uniforme de recursos">URL</abbr>.

<abbr title="HTTP protegido por criptografia">HTTPS</abbr> protege a comunicação por criptografia/autenticação do servidor, mas **não certifica a veracidade do conteúdo**.

## 3. Link e destino

O rótulo visível de um link não precisa coincidir com o endereço de destino.

- referência absoluta → localizável sem depender do endereço atual;
- referência relativa → interpretada a partir de um endereço-base.

## 4. Busca em três etapas

**descobrir/rastrear → indexar → servir/ordenar resultados**

Índice de busca **não é** todo o conteúdo vivo da Internet. Filtros e operadores dependem do serviço e podem mudar.

## 5. Navegação e dados locais

- histórico → lista de navegações conforme configuração;
- favoritos/marcadores → referências salvas para reencontrar recursos;
- download → transfere conteúdo para armazenamento;
- cache → reutiliza temporariamente recursos/respostas;
- cookies → dados de estado/preferências deixados por sites;
- navegação privativa → reduz rastros locais; **não garante anonimato**.

**Pegadinha:** histórico ≠ cache ≠ cookies.

## 6. Impressão

- voltar/avançar → percorre histórico;
- recarregar → solicita novamente o recurso atual;
- abas → mantêm recursos separados na mesma janela;
- `Ctrl+P` → atalho comum em navegadores de desktop para impressão, conforme ambiente;
- impressão pode gerar <abbr title="Portable Document Format, formato portátil de documento">PDF</abbr>, se a opção estiver disponível;
- imprimir ≠ baixar o arquivo original.

## 7. Redes sociais

Reconheça a combinação: **conta/perfil + relações/seguimento + publicação/compartilhamento + interação**.

Visibilidade depende das configurações, do tipo de publicação e das regras da plataforma. Rede social pode ser acessada por navegador ou aplicativo; ela não é sinônimo de navegador, Internet ou mecanismo de busca.

## 8. Roteiro de prova

1. Qual é o **objeto**: infraestrutura, serviço, programa, endereço, índice ou plataforma?
2. Qual é o **verbo**: interligar, navegar, localizar, indexar, imprimir ou publicar?
3. Há universalização indevida: “sempre”, “somente”, “todo”?
4. A alternativa confundiu **interface** com **mecanismo**?
5. O efeito afirmado é maior do que a tecnologia realmente garante?
