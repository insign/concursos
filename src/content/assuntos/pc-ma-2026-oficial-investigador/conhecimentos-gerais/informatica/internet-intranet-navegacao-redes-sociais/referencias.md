## Internet, intranet, Web e endereçamento

- <abbr title="National Institute of Standards and Technology">NIST</abbr>. **Computer Security Resource Center — Glossary: Internet.** Define a Internet como sistema global de redes interconectadas. Disponível em: https://csrc.nist.gov/glossary/term/Internet.
- <abbr title="National Institute of Standards and Technology">NIST</abbr>. **Computer Security Resource Center — Glossary: intranet.** Referência para o uso interno/restrito de tecnologias de rede de Internet em uma organização. Disponível em: https://csrc.nist.gov/glossary/term/intranet.
- INTERNET ENGINEERING TASK FORCE. <abbr title="Request for Comments, documento técnico da Internet">RFC</abbr> 3986 — **Uniform Resource Identifier: Generic Syntax.** Base técnica para esquema, autoridade, caminho, consulta e fragmento. Disponível em: https://www.rfc-editor.org/info/rfc3986/.
- INTERNET ENGINEERING TASK FORCE. <abbr title="Request for Comments, documento técnico da Internet">RFC</abbr> 9110 — **HTTP Semantics.** Seções 4.2.2 e 4.3.4: referência para o esquema <abbr title="HTTP protegido por criptografia">HTTPS</abbr>, proteção de confidencialidade/integridade e autenticação do servidor por certificado. Disponível em: https://www.rfc-editor.org/rfc/rfc9110.html.
- <abbr title="Mozilla Developer Network, documentação para tecnologias web">MDN</abbr> Web Docs. **Browser — Glossary.** Referência para a função do navegador como software de acesso e apresentação de recursos web. Disponível em: https://developer.mozilla.org/pt-BR/docs/Glossary/Browser.
- <abbr title="Mozilla Developer Network, documentação para tecnologias web">MDN</abbr> Web Docs. **URL — Glossary.** Referência didática para os componentes de uma <abbr title="Uniform Resource Locator, localizador uniforme de recursos">URL</abbr>. Disponível em: https://developer.mozilla.org/pt-BR/docs/Glossary/URL.
- <abbr title="Mozilla Developer Network, documentação para tecnologias web">MDN</abbr> Web Docs. **Cache — Glossário.** Referência para armazenamento temporário e reutilização de respostas web. Disponível em: https://developer.mozilla.org/pt-BR/docs/Glossary/Cache.
- <abbr title="Mozilla Developer Network, documentação para tecnologias web">MDN</abbr> Web Docs. **Cookie — Glossary.** Referência para pequenos dados mantidos por sites via navegador. Disponível em: https://developer.mozilla.org/en-US/docs/Glossary/Cookie.
- MOZILLA SUPPORT. **Lendas comuns sobre navegação privativa.** Referência para distinguir redução de rastros locais de anonimato na Internet; favoritos e arquivos baixados podem permanecer. Disponível em: https://support.mozilla.org/pt-BR/kb/mitos-comuns-sobre-navegacao-privativa.

## Busca, impressão e redes sociais

- GOOGLE. **In-depth guide to how Google Search works.** Referência para o mecanismo geral de descoberta/rastreamento, indexação e serviço de resultados; a implementação concreta é própria do mecanismo. Disponível em: https://developers.google.com/search/docs/fundamentals/how-search-works.
- MICROSOFT. **Imprimir no Microsoft Edge.** Referência para pré-visualização e opções de impressão no navegador, inclusive seleção de destino e configurações de página. Disponível em: https://support.microsoft.com/pt-br/edge/print-in-microsoft-edge.
- <abbr title="Centro de Estudos, Resposta e Tratamento de Incidentes de Segurança no Brasil">CERT.br</abbr>. **Cartilha de Segurança para Internet — Fascículo Redes Sociais.** Material institucional sobre contas, contatos, publicação/compartilhamento e interação em redes sociais; nesta unidade, serve apenas à caracterização funcional, sem antecipar o capítulo de segurança. Disponível em: https://cartilha.cert.br/fasciculos/redes-sociais/fasciculo-redes-sociais.pdf.
