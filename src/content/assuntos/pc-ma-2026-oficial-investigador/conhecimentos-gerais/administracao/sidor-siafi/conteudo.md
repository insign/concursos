# <abbr title="Sistema Integrado de Dados Orçamentários">SIDOR</abbr> e <abbr title="Sistema Integrado de Administração Financeira do Governo Federal">SIAFI</abbr>: não confunda preparar o orçamento com executar o orçamento

Imagine duas perguntas diferentes:

1. **Como o Governo Federal organiza e consolida informações para preparar e administrar o orçamento?**
2. **Como registra, acompanha e controla a execução orçamentária, financeira e patrimonial depois que o orçamento passa a ser executado?**

O edital cita dois sistemas que pertencem a momentos e funções diferentes desse fluxo: o <abbr title="Sistema Integrado de Dados Orçamentários">SIDOR</abbr> e o <abbr title="Sistema Integrado de Administração Financeira do Governo Federal">SIAFI</abbr>.

A primeira dificuldade é histórica: o <abbr title="Sistema Integrado de Dados Orçamentários">SIDOR</abbr> foi o sistema usado no orçamento federal, mas suas funcionalidades foram migradas para o <abbr title="Sistema Integrado de Planejamento e Orçamento">SIOP</abbr>. Isso **não autoriza apagar o <abbr title="Sistema Integrado de Dados Orçamentários">SIDOR</abbr> do estudo**, porque o item 2.4 do edital o nomeia expressamente.

A segunda dificuldade é funcional: o <abbr title="Sistema Integrado de Administração Financeira do Governo Federal">SIAFI</abbr> não é o sistema de elaboração da proposta orçamentária. Seu núcleo é a **execução**: registrar, acompanhar e controlar fatos orçamentários, financeiros, patrimoniais e contábeis do Governo Federal.

> **Regra de prova:** associe primeiro cada sistema ao problema que ele resolve. Depois trate das integrações entre eles.

## 1. O mapa mental em uma linha

| Sistema | Ideia central para a prova | Situação histórica |
| --- | --- | --- |
| <abbr title="Sistema Integrado de Dados Orçamentários">SIDOR</abbr> | dados e elaboração do orçamento federal | sistema histórico; substituído pelo <abbr title="Sistema Integrado de Planejamento e Orçamento">SIOP</abbr> |
| <abbr title="Sistema Integrado de Planejamento e Orçamento">SIOP</abbr> | planejamento e orçamento federal, com módulos para os macroprocessos atuais | sucessor do <abbr title="Sistema Integrado de Dados Orçamentários">SIDOR</abbr> |
| <abbr title="Sistema Integrado de Administração Financeira do Governo Federal">SIAFI</abbr> | registro, acompanhamento e controle da execução orçamentária, financeira, patrimonial e contábil | sistema de execução em uso |

Esse quadro é uma **âncora**, não uma fronteira impermeável. Sistemas governamentais trocam dados. A existência de integração não transforma um sistema no outro.

## 2. <abbr title="Sistema Integrado de Dados Orçamentários">SIDOR</abbr>: o sistema histórico de dados orçamentários

<abbr title="Sistema Integrado de Dados Orçamentários">SIDOR</abbr> significa **Sistema Integrado de Dados Orçamentários**.

Documentação oficial antiga do orçamento federal descreve o <abbr title="Sistema Integrado de Dados Orçamentários">SIDOR</abbr> como sistema que processava informações de natureza orçamentária. Entre seus componentes havia funções voltadas à elaboração da proposta, isto é, ao processamento dos dados que formariam os Orçamentos da União.

Para a prova, retenha a relação:

**<abbr title="Sistema Integrado de Dados Orçamentários">SIDOR</abbr> → informação orçamentária → elaboração/proposta do orçamento.**

Isso evita duas trocas frequentes:

- dizer que o <abbr title="Sistema Integrado de Dados Orçamentários">SIDOR</abbr> era o sistema principal de registro da execução financeira — função que aponta para o <abbr title="Sistema Integrado de Administração Financeira do Governo Federal">SIAFI</abbr>;
- dizer que o <abbr title="Sistema Integrado de Dados Orçamentários">SIDOR</abbr> administrava convênios ou folha de pessoal — confusão com outros sistemas da Administração Pública.

### 2.1 A transição para o <abbr title="Sistema Integrado de Planejamento e Orçamento">SIOP</abbr>

O manual oficial do <abbr title="Sistema Integrado de Planejamento e Orçamento">SIOP</abbr> informa que seu desenvolvimento começou em **2009**, por iniciativa da <abbr title="Secretaria de Orçamento Federal">SOF</abbr>, em substituição ao antigo <abbr title="Sistema Integrado de Dados Orçamentários">SIDOR</abbr>.

O mesmo histórico registra que:

- o <abbr title="Sistema Integrado de Planejamento e Orçamento">SIOP</abbr> passou a integrar processos de planejamento e orçamento;
- as funcionalidades do <abbr title="Sistema Integrado de Dados Orçamentários">SIDOR</abbr> foram migradas para o <abbr title="Sistema Integrado de Planejamento e Orçamento">SIOP</abbr>;
- o sistema atual trata macroprocessos como elaboração dos projetos de leis do planejamento e do orçamento, alterações orçamentárias, emendas, receitas e acompanhamento físico das ações.

Portanto, em uma questão atual, a formulação **“o <abbr title="Sistema Integrado de Dados Orçamentários">SIDOR</abbr> é hoje o sistema institucional corrente de suporte ao orçamento federal”** está desatualizada.

Mas há uma pegadinha inversa: se a banca perguntar **o que o edital expressamente menciona**, a resposta continua sendo <abbr title="Sistema Integrado de Dados Orçamentários">SIDOR</abbr> e <abbr title="Sistema Integrado de Administração Financeira do Governo Federal">SIAFI</abbr>. O <abbr title="Sistema Integrado de Planejamento e Orçamento">SIOP</abbr> entra aqui para explicar a evolução institucional, não para reescrever a fonte.

## 3. <abbr title="Sistema Integrado de Administração Financeira do Governo Federal">SIAFI</abbr>: execução, registro e controle

<abbr title="Sistema Integrado de Administração Financeira do Governo Federal">SIAFI</abbr> significa **Sistema Integrado de Administração Financeira do Governo Federal**.

Segundo a <abbr title="Secretaria do Tesouro Nacional">STN</abbr>, ele é o principal instrumento utilizado para **registro, acompanhamento e controle da execução orçamentária, financeira e patrimonial** do Governo Federal. A página institucional também explicita o processamento e o controle de informações contábeis.

A expressão **execução orçamentária** significa utilizar os créditos autorizados no orçamento. A **execução financeira** é o fluxo de recursos financeiros necessário para realizar os gastos. As duas dimensões se relacionam, mas não são sinônimas: autorização orçamentária e disponibilidade financeira respondem a perguntas diferentes.

### 3.1 Por que o <abbr title="Sistema Integrado de Administração Financeira do Governo Federal">SIAFI</abbr> foi criado?

Até 1986, a União enfrentava problemas como controles manuais, informações gerenciais deficientes, demora na escrituração e multiplicidade de fontes de dados.

A <abbr title="Secretaria do Tesouro Nacional">STN</abbr>, criada em 1986, desenvolveu o <abbr title="Sistema Integrado de Administração Financeira do Governo Federal">SIAFI</abbr> em conjunto com o <abbr title="Serviço Federal de Processamento de Dados">Serpro</abbr>. O sistema foi implantado em **janeiro de 1987**.

Essa origem ajuda a lembrar sua vocação: integrar e tornar tempestivo o controle da execução das finanças públicas federais.

## 4. Objetivos do <abbr title="Sistema Integrado de Administração Financeira do Governo Federal">SIAFI</abbr> que mais rendem questão

A lista oficial é extensa. Para prova, agrupe-a por mecanismo.

### 4.1 Controle diário

O <abbr title="Sistema Integrado de Administração Financeira do Governo Federal">SIAFI</abbr> busca prover mecanismos adequados ao **controle diário** da execução orçamentária, financeira e patrimonial.

**Pegadinha:** trocar “diário” por “mensal” reduz indevidamente a finalidade do sistema.

### 4.2 Programação financeira e caixa

Um objetivo é agilizar a **programação financeira**, isto é, o planejamento dos fluxos de recursos financeiros necessários à execução, favorecendo o uso eficiente dos recursos do Tesouro.

### 4.3 Informação contábil e padronização

O sistema deve permitir que a contabilidade pública forneça informação gerencial segura e tempestiva e deve padronizar métodos e rotinas de gestão dos recursos públicos.

Padronizar não significa retirar toda autonomia do responsável pela gestão. A própria descrição oficial rejeita a ideia de rigidez absoluta.

### 4.4 Integração, acompanhamento e transparência

Também são objetivos relevantes:

- integrar e compatibilizar informações no Governo Federal;
- permitir acompanhamento e avaliação do uso dos recursos públicos;
- proporcionar transparência dos gastos federais.

Note o padrão: todos esses objetivos estão ligados à **execução e à informação gerada por ela**, não à função de elaborar o projeto de orçamento anual.

## 5. Como o <abbr title="Sistema Integrado de Administração Financeira do Governo Federal">SIAFI</abbr> se organiza

A estrutura do <abbr title="Sistema Integrado de Administração Financeira do Governo Federal">SIAFI</abbr> é hierárquica.

1. **Exercício:** cada ano corresponde a um sistema do respectivo exercício.
2. **Subsistema:** divisão ampla de funcionalidades com finalidade própria.
3. **Módulo:** agrupamento de funções relacionadas dentro de um subsistema.
4. **Transação:** nível em que são executadas operações, desde entradas de dados até consultas.

Em prova, memorize a ordem:

**exercício → subsistema → módulo → transação.**

Não é necessário decorar aqui a quantidade de subsistemas, porque esse número é atributo operacional sujeito a mudança e o edital cobra apenas <abbr title="Sistema Integrado de Dados Orçamentários">SIDOR</abbr>/<abbr title="Sistema Integrado de Administração Financeira do Governo Federal">SIAFI</abbr> de forma geral.

## 6. <abbr title="Sistema Integrado de Dados Orçamentários">SIDOR</abbr>/<abbr title="Sistema Integrado de Planejamento e Orçamento">SIOP</abbr> e <abbr title="Sistema Integrado de Administração Financeira do Governo Federal">SIAFI</abbr> se complementam

A elaboração do orçamento e sua execução formam etapas relacionadas do ciclo orçamentário.

A documentação da <abbr title="Secretaria do Tesouro Nacional">STN</abbr> registra que, depois de publicada a lei orçamentária e observadas as regras de execução, informações orçamentárias fornecidas pela <abbr title="Secretaria de Orçamento Federal">SOF</abbr> alimentam o <abbr title="Sistema Integrado de Administração Financeira do Governo Federal">SIAFI</abbr> para que a execução seja registrada.

Daí saem duas conclusões importantes:

- integração de dados **não** significa identidade de finalidade;
- o sistema de planejamento/orçamento e o sistema de execução precisam conversar porque a execução depende de autorização orçamentária.

### Exemplo hipotético

Imagine que um órgão tenha uma dotação aprovada para adquirir equipamentos.

- A elaboração e a organização da informação orçamentária pertencem ao eixo historicamente associado ao <abbr title="Sistema Integrado de Dados Orçamentários">SIDOR</abbr> e hoje suportado pelo <abbr title="Sistema Integrado de Planejamento e Orçamento">SIOP</abbr>.
- Quando começa a execução da despesa e seus registros orçamentários, financeiros, patrimoniais e contábeis, entra o eixo do <abbr title="Sistema Integrado de Administração Financeira do Governo Federal">SIAFI</abbr>.

O exemplo é apenas didático: não transforma cada fase do processo em um sistema isolado nem pretende listar todas as integrações técnicas existentes.

## 7. O que não importar do doador TCE

O material do <abbr title="Tribunal de Contas do Estado do Maranhão">TCE-MA</abbr> usado como origem parcial aprofunda o módulo <abbr title="Contas a Pagar e a Receber">CPR</abbr>, documentos hábeis, compromissos, pré-documentos e rotinas de realização.

Esse aprofundamento é útil para um edital que cobre <abbr title="Contas a Pagar e a Receber">CPR</abbr>, mas **não integra o item 2.4 da <abbr title="Polícia Civil do Maranhão">PC-MA</abbr>**, que cita apenas <abbr title="Sistema Integrado de Dados Orçamentários">SIDOR</abbr> e <abbr title="Sistema Integrado de Administração Financeira do Governo Federal">SIAFI</abbr>.

Por isso, esta unidade aproveita do doador somente:

- conceito e finalidade do <abbr title="Sistema Integrado de Administração Financeira do Governo Federal">SIAFI</abbr>;
- posição do sistema na execução federal;
- estrutura em exercícios, subsistemas, módulos e transações.

O restante foi cortado para preservar tempo de estudo e aderência ao edital.

## 8. Método de ataque em questão

Ao encontrar uma alternativa sobre sistemas federais, use quatro perguntas:

1. **É orçamento ou execução?** Elaboração/planejamento aponta para o eixo <abbr title="Sistema Integrado de Dados Orçamentários">SIDOR</abbr> histórico / <abbr title="Sistema Integrado de Planejamento e Orçamento">SIOP</abbr> atual; execução aponta para <abbr title="Sistema Integrado de Administração Financeira do Governo Federal">SIAFI</abbr>.
2. **A alternativa respeita a cronologia?** <abbr title="Sistema Integrado de Dados Orçamentários">SIDOR</abbr> é histórico; <abbr title="Sistema Integrado de Planejamento e Orçamento">SIOP</abbr> é seu sucessor.
3. **A finalidade do <abbr title="Sistema Integrado de Administração Financeira do Governo Federal">SIAFI</abbr> foi trocada?** Compras, folha de pessoal, gestão documental e convênios têm sistemas próprios; não converta tudo em <abbr title="Sistema Integrado de Administração Financeira do Governo Federal">SIAFI</abbr>.
4. **A estrutura está na ordem certa?** No <abbr title="Sistema Integrado de Administração Financeira do Governo Federal">SIAFI</abbr>: exercício → subsistema → módulo → transação.

Se essas quatro checagens estiverem corretas, a maior parte das pegadinhas do item 2.4 perde força.
