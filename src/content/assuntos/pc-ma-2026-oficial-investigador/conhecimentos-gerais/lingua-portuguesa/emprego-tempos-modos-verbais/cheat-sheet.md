# Emprego de tempos e modos verbais

## Eixo de análise

Não pare no nome do tempo verbal. Pergunte:

1. qual é o ponto de referência?
2. o evento é anterior, simultâneo ou posterior?
3. é visto como concluído, em curso, habitual ou repetido?
4. a frase afirma, deseja, condiciona, ordena, avalia ou infere?

**Tempo verbal ≠ tempo cronológico.** Forma correta também não significa sentido preservado.

## Quatro planos

| Plano | Pergunta |
| --- | --- |
| tempo | quando em relação ao ponto de referência? |
| aspecto | como o processo é apresentado internamente? |
| modo | indicativo, subjuntivo ou imperativo? |
| modalidade | certeza assumida, hipótese, desejo, obrigação, inferência etc.? |

## Indicativo: valores frequentes

| Forma | Valores que mais caem |
| --- | --- |
| presente | atual, habitual, geral, histórico, futuro programado |
| perfeito | evento delimitado; progressão narrativa |
| imperfeito | processo em curso, hábito, cenário, simultaneidade, polidez |
| mais-que-perfeito | anterioridade a outro passado |
| futuro do presente | posterioridade, previsão, inferência, ordem |
| futuro do pretérito | posterioridade relativa ao passado, hipótese, polidez, distanciamento |

### Contrastes rápidos

- `leu` → evento delimitado.
- `lia` → processo em curso/hábito/fundo narrativo.
- `quando chegou, já lera/havia lido` → leitura anterior à chegada.
- `amanhã viajo` → presente com valor futuro.
- `em 1822, o Brasil rompe...` → presente histórico.
- `eu queria pedir...` → imperfeito de polidez.
- `ele terá quarenta anos` → futuro como estimativa.
- `segundo a notícia, teria ocorrido` → futuro do pretérito com reserva/distanciamento.

## Aspecto

- **perfectivo:** processo focalizado como delimitado — `analisou`.
- **imperfectivo:** visto internamente, sem foco no limite — `analisava`.
- **progressivo:** `estava analisando`.
- **habitual:** `analisava toda semana`.
- **reiterado/durativo até o presente:** `tem analisado`.
- **início:** `passou a analisar`.
- **continuidade:** `continua analisando`.
- **retomada:** `voltou a analisar`.
- **interrupção/não ocorrência:** `deixou de analisar`.

## Indicativo × subjuntivo

| Construção | Tendência |
| --- | --- |
| `sei que`, `é certo que` | indicativo |
| `espero que`, `desejo que` | subjuntivo |
| `é necessário/importante que` | subjuntivo |
| `embora`, `ainda que` | subjuntivo |
| `caso`, `contanto que` | subjuntivo |
| `quando` + evento futuro eventual | futuro do subjuntivo |

**Pegadinha:** `que` sozinho não exige subjuntivo.

- `sei que há` × `espero que haja`.
- `procuro o servidor que conhece` → referente apresentado como identificado.
- `procuro um servidor que conheça` → referente eventual.

## Subjuntivo

| Tempo | Exemplo |
| --- | --- |
| presente | `Espero que venha.` |
| imperfeito | `Se viesse, conversaríamos.` |
| futuro | `Quando vier, conversaremos.` |

### Futuro do subjuntivo × infinitivo

- `quando analisar` → pode ser futuro do subjuntivo.
- `para analisar` → infinitivo.
- `quando fizer`, não `quando fazer`.
- `se vir o erro` = verbo **ver**.
- `quando vier ao local` = verbo **vir**.

### Formas irregulares que merecem memória

| Infinitivo | Futuro do subjuntivo |
| --- | --- |
| ter / manter / obter | tiver / mantiver / obtiver |
| fazer | fizer |
| dizer / trazer | disser / trouxer |
| pôr / propor | puser / propuser |
| vir / intervir | vier / intervier |
| ver / prever | vir / previr |
| reaver / caber | reouver / couber |
| requerer | requerer |

Atalho útil: em muitos verbos, parta da 3ª pessoa do plural do perfeito e retire `-am`: `fizeram → fizer`, `vieram → vier`, `viram → vir`.

## Correlação e condicionais

A **prótase** apresenta a condição; a **apódose**, a consequência.

| Leitura | Padrão |
| --- | --- |
| hábito | `Se estuda, aprende.` |
| futuro aberto | `Se estudar, aprenderá.` |
| instrução | `Se houver dúvida, consulte.` |
| hipótese distante | `Se estudasse, aprenderia.` |
| passado não realizado | `Se tivesse estudado, teria aprendido.` |
| condição passada + efeito atual | `Se tivesse estudado, estaria tranquilo.` |

`Não sei se teria condições` é pergunta indireta; `se teria` não é erro automático.

## Imperativo

| Pessoa | Afirmativo | Negativo |
| --- | --- | --- |
| tu | fala | não fales |
| você | fale | não fale |
| nós | falemos | não falemos |
| vós | falai | não faleis |
| vocês | falem | não falem |

- não há imperativo de `eu`;
- `você` usa flexão de terceira pessoa;
- `ser`: `sê` / `sede` no afirmativo;
- ordem pode aparecer fora do imperativo: `Você entregará o relatório amanhã.`

## Locuções e tempos compostos

| Construção | Valor frequente |
| --- | --- |
| `tem analisado` | repetição/duração até o presente |
| `tinha analisado` | anterioridade passada |
| `estava analisando` | processo em curso no passado |
| `vai analisar` | projeção futura |
| `acabou de analisar` | passado recente |
| `deve analisar` | obrigação/probabilidade |
| `pode analisar` | possibilidade/permissão/capacidade |

`revisou` ≠ automaticamente `tem revisado`: o perfeito composto, no português brasileiro, tende a marcar repetição ou duração até o presente.

## Discurso relatado

| Direto | Relato ancorado no passado |
| --- | --- |
| `Voltarei amanhã.` | disse que `voltaria no dia seguinte` |
| `Estou analisando.` | disse que `estava analisando` |
| `Concluí.` | disse que `havia concluído/concluíra` |
| `Venha agora.` | ordenou que `viesse naquele momento` |

A mudança depende do novo ponto de referência; não é transformação mecânica.

## Método de reescrita

Cheque separadamente:

1. correção gramatical;
2. ordem temporal dos fatos;
3. aspecto;
4. modo/modalidade;
5. correlação entre orações;
6. coerência global.

Exemplo decisivo:

- `iam ocorrer` → `ocorreriam`: pode preservar a projeção futura a partir do passado;
- `iam ocorrer` → `ocorriam`: pode ser gramatical, mas tende a mudar para simultaneidade/hábito passado.

## Pegadinhas finais

- subjuntivo ≠ dúvida obrigatória;
- indicativo ≠ verdade comprovada;
- todo futuro ≠ posterioridade literal;
- toda mistura de tempos ≠ erro;
- `quando chegará?` é pergunta direta; `quando chegar, avise` traz futuro do subjuntivo;
- `ver → vir` e `vir → vier` no futuro do subjuntivo;
- `requerer → requerer`, não `requiser`;
- forma verbal correta pode alterar o sentido da reescrita.
