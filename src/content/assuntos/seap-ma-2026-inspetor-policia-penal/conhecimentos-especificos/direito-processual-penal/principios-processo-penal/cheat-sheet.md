# Princípios do processo penal — revisão rápida

## Mapa central

**Processo legítimo = devido processo + juiz natural + contraditório + ampla defesa + não culpabilidade + não autoincriminação + publicidade/fundamentação + prova lícita + duração razoável + estrutura acusatória.**

## Gatilhos de prova

- **devido processo** → poder punitivo dentro de procedimento juridicamente válido;
- **juiz natural** → sem tribunal de exceção + autoridade previamente competente;
- **contraditório** → ciência + possibilidade real de influência;
- **ampla defesa** → defesa técnica + participação defensiva;
- **não culpabilidade** → sem culpa definitiva antes do trânsito em julgado;
- **não autoincriminação** → <abbr title="Ninguém é obrigado a produzir prova contra si">nemo tenetur se detegere</abbr>;
- **publicidade** → regra, com restrições justificadas;
- **fundamentação** → decisão precisa mostrar razões;
- **prova ilícita** → inadmissível;
- **duração razoável** → celeridade com garantias;
- **estrutura acusatória** → separar acusar de julgar.

## Contrastes

| Não confunda | Com |
| --- | --- |
| inquérito | processo judicial |
| contraditório | mera ciência formal |
| não culpabilidade | proibição de toda cautelar |
| silêncio | confissão |
| publicidade | fundamentação |
| iniciativa judicial pontual | juiz atuando como acusador |

Tema 907/<abbr title="Supremo Tribunal Federal">STF</abbr>: não autoincriminação não é imunidade geral contra qualquer dever jurídico.

Art. 3º-A do <abbr title="Código de Processo Penal">CPP</abbr> + <abbr title="Ações Diretas de Inconstitucionalidade">ADIs</abbr> 6.298/6.299/6.300/6.305 → estrutura acusatória preservada; diligências judiciais suplementares pontuais podem existir nos limites legais.

## Pegadinhas

- tribunal criado para o caso → problema de juiz natural;
- defesa sem chance de influir → contraditório insuficiente;
- decisão sem razões → falta de fundamentação;
- prova ilícita → inadmissível;
- investigação com traços inquisitivos ≠ processo judicial inquisitivo.
