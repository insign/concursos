# Emprego de tempos e modos verbais

## Eixo de prova

Não pare no nome do tempo. Pergunte:

1. qual é o ponto de referência?
2. o fato é anterior, simultâneo ou posterior?
3. é visto como concluído, em curso, habitual ou repetido?
4. a frase afirma, deseja, condiciona, ordena ou infere?

**Tempo verbal ≠ tempo cronológico.** Forma gramaticalmente correta também não garante sentido preservado.

## Indicativo: valores principais

| Forma | Valores frequentes |
| --- | --- |
| presente | atual, habitual, geral, histórico, futuro programado |
| perfeito | evento delimitado; progressão narrativa |
| imperfeito | curso, hábito, cenário, simultaneidade, polidez |
| mais-que-perfeito | anterioridade a outro passado |
| futuro do presente | posterioridade, previsão, inferência, ordem |
| futuro do pretérito | futuro relativo ao passado, hipótese, polidez, distanciamento |

Contrastes:

- `leu` → evento delimitado; `lia` → curso/hábito/fundo.
- `já lera/havia lido` → fato anterior a outro passado.
- `amanhã viajo` → presente com valor futuro.
- `eu queria pedir...` → imperfeito de polidez.
- `ele terá quarenta anos` → futuro como estimativa.
- `segundo a notícia, teria ocorrido` → futuro do pretérito com reserva.

## Aspecto

- **perfectivo:** `analisou` — processo focalizado como delimitado.
- **imperfectivo:** `analisava` — visto internamente.
- **progressivo:** `estava analisando`.
- **reiterado/durativo:** `tem analisado`.
- início: `passou a analisar`.
- continuidade: `continua analisando`.
- retomada: `voltou a analisar`.
- interrupção: `deixou de analisar`.

## Indicativo × subjuntivo

| Construção | Tendência |
| --- | --- |
| `sei que`, `é certo que` | indicativo |
| `espero/desejo que` | subjuntivo |
| `é necessário que` | subjuntivo |
| `embora`, `ainda que` | subjuntivo |
| `caso`, `contanto que` | subjuntivo |
| `quando` + evento futuro eventual | futuro do subjuntivo |

- `sei que há` × `espero que haja`.
- `procuro o servidor que conhece` → referente identificado.
- `procuro um servidor que conheça` → referente eventual.

**Pegadinha:** `que` sozinho não exige subjuntivo.

## Tempos do subjuntivo

- presente: `Espero que venha.`
- imperfeito: `Se viesse, conversaríamos.`
- futuro: `Quando vier, conversaremos.`

### Futuro do subjuntivo

- `quando analisar` pode coincidir com o infinitivo `para analisar`.
- `quando fizer`, não `quando fazer`.
- verbo **ver**: `se vir o erro`.
- verbo **vir**: `quando vier ao local`.

| Infinitivo | Futuro do subjuntivo |
| --- | --- |
| ter / manter / obter | tiver / mantiver / obtiver |
| fazer | fizer |
| dizer / trazer | disser / trouxer |
| pôr / propor | puser / propuser |
| vir / intervir | vier / intervier |
| ver / prever | vir / previr |
| reaver / caber | reouver / couber |
| requerer | requerer |

Atalho: muitas formas vêm da 3ª pessoa plural do perfeito sem `-am`: `fizeram → fizer`, `vieram → vier`, `viram → vir`.

## Condicionais e correlação

| Leitura | Padrão |
| --- | --- |
| hábito | `Se estuda, aprende.` |
| futuro aberto | `Se estudar, aprenderá.` |
| instrução | `Se houver dúvida, consulte.` |
| hipótese distante | `Se estudasse, aprenderia.` |
| passado não realizado | `Se tivesse estudado, teria aprendido.` |
| condição passada + efeito atual | `Se tivesse estudado, estaria tranquilo.` |

Mistura de tempos não é erro automático. `Não sei se teria condições` traz pergunta indireta; esse `se` não introduz condição.

## Imperativo

| Pessoa | Afirmativo | Negativo |
| --- | --- | --- |
| tu | fala | não fales |
| você | fale | não fale |
| nós | falemos | não falemos |
| vós | falai | não faleis |
| vocês | falem | não falem |

- não há imperativo de `eu`;
- `você` recebe flexão de terceira pessoa;
- `ser`: `sê` / `sede`;
- futuro também pode ordenar: `Você entregará o relatório amanhã.`

## Locuções e compostos

| Construção | Valor frequente |
| --- | --- |
| `tem analisado` | repetição/duração até o presente |
| `tinha analisado` | anterioridade passada |
| `estava analisando` | processo em curso no passado |
| `vai analisar` | projeção futura |
| `acabou de analisar` | passado recente |
| `deve analisar` | obrigação/probabilidade |
| `pode analisar` | possibilidade/permissão/capacidade |

`revisou` não equivale automaticamente a `tem revisado`: o perfeito composto tende a marcar repetição ou duração até o presente.

## Discurso relatado

- `Voltarei amanhã.` → disse que `voltaria no dia seguinte`.
- `Estou analisando.` → disse que `estava analisando`.
- `Concluí.` → disse que `havia concluído/concluíra`.
- `Venha agora.` → ordenou que `viesse naquele momento`.

A mudança depende do novo ponto de referência; não é mecânica.

## Reescrita

Cheque separadamente:

1. correção gramatical;
2. ordem temporal;
3. aspecto;
4. modo/modalidade;
5. correlação entre orações;
6. sentido global.

`iam ocorrer → ocorreriam` pode preservar projeção futura a partir do passado; `iam ocorrer → ocorriam` pode ser gramatical e, ainda assim, mudar para simultaneidade ou hábito passado.

## Pegadinhas

- subjuntivo ≠ dúvida obrigatória;
- indicativo ≠ verdade comprovada;
- todo futuro ≠ posterioridade literal;
- toda mistura de tempos ≠ erro;
- `quando chegará?` ≠ `quando chegar, avise`;
- `ver → vir`; `vir → vier`;
- `requerer → requerer`, não `requiser`.
