# Internet e navegação — revisão rápida

## Funções

Internet → infraestrutura  
Web → serviço sobre Internet  
navegador → apresenta recursos  
<abbr title="Uniform Resource Locator, localizador uniforme de recursos">URL</abbr> → localiza recurso  
link → aponta  
busca → consulta índice  
impressão → produz saída

## <abbr title="Uniform Resource Locator, localizador uniforme de recursos">URL</abbr>

`https://host/caminho?consulta#fragmento`

<abbr title="Hypertext Transfer Protocol Secure, HTTP protegido por criptografia">HTTPS</abbr> protege o canal ≠ certifica conteúdo.

## Busca

rastrear → indexar → recuperar/ordenar

índice ≠ toda a Internet ao vivo

operadores/filtros dependem do serviço.

## Navegação

recarregar ≠ voltar  
download ≠ abrir página  
histórico ≠ cache ≠ cookies  
modo privativo ≠ anonimato

## Impressão

`Ctrl+P` → comum em desktop  
pode gerar <abbr title="Portable Document Format, formato portátil de documento">PDF</abbr> conforme ambiente  
imprimir ≠ baixar arquivo original

## Roteiro

objeto → verbo → destino real → limite da tecnologia → elimine universalizações
