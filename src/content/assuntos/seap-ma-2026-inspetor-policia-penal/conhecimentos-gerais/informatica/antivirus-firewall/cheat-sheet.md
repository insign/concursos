# Antivírus e firewall — revisão rápida

## Função

antivírus/antimalware → código e comportamento suspeitos  
firewall → tráfego de rede segundo regras

## Antimalware

assinatura → padrão conhecido  
heurística → indícios  
comportamento → ações  
reputação → origem/prevalência

falso positivo → legítimo marcado como ameaça  
falso negativo → ameaça não detectada  
quarentena → **isola**, não é sinônimo de excluir

## Firewall

host → próprio equipamento  
rede → segmento/fronteira  
sem estado → pacote isolado  
com estado → acompanha conexão

Firewall **não** remove malware do disco nem corrige vulnerabilidade.

## Eliminação

arquivo/comportamento → antimalware  
porta/conexão/tráfego → firewall  
recuperação de dados → cópia de segurança

**Camadas se complementam; nenhuma garante proteção total.**
