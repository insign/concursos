# Microsoft Excel — revisão rápida

## Três camadas

valor armazenado ≠ fórmula ≠ formato exibido

- `0,25` + formato % → `25%`;
- reduzir casas → muda exibição, não necessariamente o valor;
- Pincel de Formatação → aparência, não fórmula.

## Quatro operações

`+` soma · `-` subtrai · `*` multiplica · `/` divide

**Precedência:** parênteses → multiplicação/divisão → adição/subtração.

`=2+3*4` → 14  
`=(2+3)*4` → 20

## Referências

`A1` relativa  
`$A$1` fixa coluna e linha  
`$A1` fixa coluna  
`A$1` fixa linha

## Formatação condicional

regra → aparência.  
**Não muda, por si, o valor armazenado.**

## Gráficos

comparar categorias → colunas/barras  
tempo → linhas  
partes de um todo simples → pizza/rosca  
duas variáveis numéricas → dispersão

**Roteiro:** conteúdo → cálculo → apresentação.
