# Sistema operacional e software — revisão rápida

## Camadas

hardware → componentes físicos  
sistema operacional → gerencia recursos + serviços  
aplicativo → tarefa do usuário  
firmware → software no próprio dispositivo  
arquivo → dados armazenados

## Não confunda

sistema operacional ≠ interface gráfica  
gerenciador de arquivos ≠ sistema inteiro  
programa ≠ processo  
atalho ≠ programa instalado  
extensão ≠ formato interno

## Operações

copiar → origem permanece  
mover → muda localização  
atalho → referência  
desinstalar → remove aplicativo pelo mecanismo próprio

## Associação

tipo de arquivo → aplicativo padrão

Mudar aplicativo padrão **não converte** o arquivo.

## Driver

software que permite ao sistema controlar dispositivo.

## Roteiro

camada → ação → objeto → consequência → elimine “sempre/somente” indevidos
