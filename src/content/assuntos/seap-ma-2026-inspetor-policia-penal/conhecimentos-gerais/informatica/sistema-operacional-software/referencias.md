## Fontes conceituais

1. **<abbr title="National Institute of Standards and Technology">NIST</abbr> — Glossary: Operating System.** Define sistema operacional como software que gerencia recursos e fornece plataforma/serviços para programas.
   https://csrc.nist.gov/glossary/term/Operating_System

2. **<abbr title="National Institute of Standards and Technology">NIST</abbr> — Glossary: software e firmware.** Sustenta a distinção entre programas/dados executáveis e software armazenado no próprio hardware.
   https://csrc.nist.gov/glossary/term/software
   https://csrc.nist.gov/glossary/term/firmware

3. **Microsoft — File Explorer in Windows; Windows desktop environment.** Apoio para a diferença entre sistema operacional, interface e aplicativo de gerenciamento de arquivos.
   https://support.microsoft.com/en-us/windows/experience/fileexplorer/file-explorer-in-windows
   https://learn.microsoft.com/pt-br/windows/win32/user-interface
