# Teclas de atalho — revisão rápida

## Windows

`Alt + Tab` → alternar janelas  
`Alt + F4` → fechar ativo  
`Win + D` → área de trabalho  
`Win + E` → Explorador  
`Win + I` → Configurações  
`Win + L` → bloquear  
`Ctrl + Shift + Esc` → Gerenciador de Tarefas

## Explorador

`Ctrl + Shift + N` → nova pasta  
`F2` → renomear  
`Alt + Enter` → propriedades  
`Ctrl + E/F` ou `F3` → pesquisar  
`Ctrl + Z` → desfazer operação compatível

## Word pt-BR — no ambiente indicado

`Ctrl + B` → salvar  
`Ctrl + T` → selecionar tudo  
`Ctrl + L` → pesquisar  
`Shift + Enter` → nova linha, mesmo parágrafo  
`Ctrl + Enter` → nova página  
`F9` → atualizar campos

## Excel

`Ctrl + 1` → Formatar Células  
`F2` → editar célula  
`F4` na referência da fórmula → alternar relativo/misto/absoluto

**Nunca ignore aplicativo, idioma, versão e foco.**
