# Teclas de atalho: contexto antes da combinação

O mesmo teclado atende programas diferentes. Por isso, uma questão sobre atalhos começa com quatro perguntas:

**aplicativo → ambiente → idioma → foco atual**

Uma combinação pode ser estável no Windows e localizada no Word; uma tecla de função pode mudar conforme o objeto selecionado. Memorizar apenas “Ctrl + letra” sem contexto aumenta o risco de erro.

## 1. Atalhos gerais e Windows

Algumas combinações aparecem em muitos aplicativos:

| Ação | Atalho comum |
|---|---|
| copiar | `Ctrl + C` |
| recortar | `Ctrl + X` |
| colar | `Ctrl + V` |
| desfazer | `Ctrl + Z` |
| alternar entre aplicativos/janelas | `Alt + Tab` |
| fechar item ou aplicativo ativo | `Alt + F4` |

No Windows, a tecla `Win` introduz vários comandos do sistema:

| Ação | Atalho |
|---|---|
| mostrar/ocultar área de trabalho | `Win + D` |
| abrir Explorador de Arquivos | `Win + E` |
| abrir Configurações | `Win + I` |
| bloquear o computador | `Win + L` |
| Configurações Rápidas no Windows 11 | `Win + A` |
| Visão de Tarefas | `Win + Tab` |

`Ctrl + Shift + Esc` abre o Gerenciador de Tarefas. Fechar uma janela e bloquear a sessão são ações diferentes: `Alt + F4` atua sobre o item ativo; `Win + L` mantém a sessão e exige nova autenticação para voltar.

## 2. Explorador de Arquivos

No Explorador, o foco muda o efeito da tecla. Atalhos úteis:

- `Ctrl + Shift + N` → criar nova pasta;
- `F2` → renomear item selecionado;
- `Alt + Enter` → abrir propriedades;
- `Ctrl + E`, `Ctrl + F` ou `F3` → pesquisa;
- `Delete` ou `Ctrl + D` → exclusão comum para a Lixeira quando aplicável;
- `Ctrl + Z` → desfazer operação recente compatível;
- `Alt + ←/→` → voltar/avançar na navegação;
- `Alt + ↑` → pasta superior.

**Selecionar tudo** também depende do foco: `Ctrl + A` pode selecionar os itens de uma janela; em um campo de texto, seleciona o texto daquele campo.

## 3. Word: letras podem ser localizadas

No Word para Windows, a documentação em português brasileiro apresenta atalhos localizados. No ambiente cobrado pela Assembleia Legislativa de Rondônia em 2026 — Word 365 e Windows 10 em português brasileiro — apareceram:

- `Ctrl + B` → salvar;
- `Ctrl + T` → selecionar todo o documento;
- `Ctrl + Z` → desfazer;
- `Ctrl + L` → pesquisar.

Isso não autoriza transportar automaticamente essas letras para outra língua, plataforma ou aplicativo.

Outros atalhos úteis do Word dependem menos de letras localizadas:

- `Shift + Enter` → quebra de linha no mesmo parágrafo;
- `Ctrl + Enter` → quebra de página;
- `F7` → verificação ortográfica/gramatical conforme versão;
- `F9` → atualizar campos selecionados;
- `Ctrl + Home` / `Ctrl + End` → início/fim do documento.

## 4. Excel: célula e fórmula mudam o contexto

No Excel para Windows:

- `Ctrl + 1` → caixa **Formatar Células**;
- `F2` → editar a célula ativa;
- `F4`, quando uma referência está selecionada na fórmula → alternar entre referência relativa, mista e absoluta;
- `Ctrl + C/X/V/Z` → copiar, recortar, colar e desfazer em contextos compatíveis.

A tecla `F4` é um bom exemplo de contexto: fora da edição de referência, também pode repetir a última ação possível. A questão precisa indicar a situação.

## 5. Método de prova

Antes de escolher a alternativa:

1. localize o aplicativo: Windows, Explorador, Word ou Excel;
2. confira versão, idioma e plataforma quando o atalho usa letras;
3. identifique o foco: item, célula, fórmula, texto ou janela;
4. diferencie ação de sistema e ação de aplicativo;
5. rejeite equivalências universais não sustentadas pelo enunciado.

**Atalho correto = combinação + contexto correto.**
