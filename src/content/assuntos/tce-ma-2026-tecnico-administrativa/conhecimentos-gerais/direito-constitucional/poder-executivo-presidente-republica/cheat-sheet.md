# Poder Executivo — recuperação rápida

## 1. Mapa

```text
76 → Presidente exerce Executivo
77 → eleição
78 → posse
79 → Vice: substitui / sucede
80 → linha de substituição
81 → dupla vacância
82 → mandato
83 → ausência do País
84 → ATRIBUIÇÕES
85 → crimes de responsabilidade
86 → processamento
52 → julgamento no Senado
```

## 2. Titularidade

```text
EXECUTIVO FEDERAL
→ PRESIDENTE
→ auxiliado por MINISTROS
```

## 3. Eleição

```text
1º TURNO → 1º domingo de outubro
2º TURNO → último domingo de outubro

MAIORIA ABSOLUTA
→ votos VÁLIDOS
→ brancos/nulos fora
```

Presidente eleito → leva o Vice registrado.

## 4. Posse

```text
POSSE → Congresso
10 dias sem assumir → vaga
EXCEÇÃO → força maior
```

## 5. Substituição × sucessão

| Situação | Vice |
|---|---|
| impedimento | **substitui** |
| vaga | **sucede** |

## 6. Linha do art. 80

```text
CÂMARA
↓
SENADO

STF
```

## 7. Dupla vacância

```text
REGRA
→ eleição 90 dias após última vaga

ÚLTIMOS 2 ANOS
→ Congresso Nacional
→ 30 dias após última vaga
```

`ELEITOS → apenas completam o período`

## 8. Mandato e ausência

```text
MANDATO → 4 anos
INÍCIO → 5 de janeiro

AUSÊNCIA DO PAÍS > 15 dias
→ licença do Congresso
→ sem licença = perda do cargo
```

# Art. 84

## 9. Administração + legislação

| Inciso | Chave |
|---:|---|
| I | nomeia/exonera Ministros |
| II | direção superior administração federal |
| III | inicia processo legislativo |
| IV | sanciona/promulga/publica + regulamento |
| V | veto total/parcial |
| XXVI | medida provisória |

## 10. Decreto — VI

```text
ORGANIZAÇÃO/FUNCIONAMENTO
→ sem aumento de despesa
→ sem criar órgão
→ sem extinguir órgão

EXTINÇÃO
→ função/cargo
→ só se VAGO
```

Contraste:

```text
IV → regulamento para fiel execução da lei
VI → decreto com campo constitucional próprio
```

## 13. Nomeações com Senado — XIV

```text

```

`NEM TODA NOMEAÇÃO EXIGE SENADO`

## 14. Delegação — decore

```text
DELEGÁVEIS
VI
XII
XXV — 1ª PARTE
```

Tradução:

```text
VI  → decreto
XII → indulto + comutação
XXV → PROVER cargos federais
```

Delegatários:

```text
MINISTRO DE ESTADO
PGR
AGU
```

Não entram: veto, MP, nomeação <abbr title="Supremo Tribunal Federal">STF</abbr>, declaração de guerra.

# Responsabilidade

## 15. Art. 85 — sete núcleos

```text
1 existência da UNIÃO
2 livre exercício dos PODERES/MP/entes
3 DIREITOS políticos/individuais/sociais
4 SEGURANÇA interna
5 PROBIDADE
6 LEI ORÇAMENTÁRIA
7 LEIS + DECISÕES JUDICIAIS
```

## 16. Lei 1.079/1950

```text
QUALQUER CIDADÃO
→ pode denunciar Presidente
→ por crime de responsabilidade
→ perante CÂMARA
```

A lei é anterior à <abbr title="Constituição Federal de 1988">CF/88</abbr>: Constituição prevalece em conflito.

## 17. Fluxo art. 86

```text
ACUSAÇÃO
↓
2/3 CÂMARA
↓
COMUM → STF
RESPONSABILIDADE → SENADO
```

`CÂMARA ADMITE; NÃO JULGA DEFINITIVAMENTE`

## 18. Suspensão

```text
COMUM
2/3 Câmara
→ STF RECEBE denúncia/queixa
→ suspensão

RESPONSABILIDADE
2/3 Câmara
→ Senado INSTAURA processo
→ suspensão
```

`AUTORIZAÇÃO DA CÂMARA SOZINHA ≠ suspensão`

## 19. 180 dias

```text
180 dias sem julgamento concluído
→ cessa AFASTAMENTO
→ PROCESSO CONTINUA
```

## 20. Art. 86 §§ 3º e 4º

```text
§3º
infração comum + sem condenação
→ Presidente não sujeito a prisão

§4º
durante o mandato
→ não responsabilizado por atos estranhos às funções
```

`§4º ≠ imunidade eterna`

## 21. Senado — art. 52

```text
CRIME DE RESPONSABILIDADE

Senado processa + julga
Presidente STF preside julgamento
Condenação → 2/3 Senado

EFEITOS
→ perda do cargo
→ inabilitação por 8 anos
```

## 22. Lei antiga × Constituição

```text
Lei 1.079 → referência histórica a até 5 anos
CF art. 52 p.u. → 8 ANOS
```

Para prova constitucional vigente → **8 anos**.

## 24. Pegadinhas

| Afirmação | Julgamento |
|---|---|
| Ministros exercem Executivo junto com Presidente | **ERRADO** |
| Vice substitui no impedimento | **CERTO** |
| Vice sucede na vaga | **CERTO** |
| linha é Senado → Câmara → STF | **ERRADO** |
| dupla vacância sempre é eleição pelo Congresso | **ERRADO** |
| eleitos iniciam novo mandato de 4 anos | **ERRADO** |
| decreto pode extinguir órgão | **ERRADO** |
| decreto pode extinguir cargo ocupado | **ERRADO** |
| veto é delegável | **ERRADO** |
| indulto é delegável | **CERTO** |
| prover cargo federal pode ser delegado | **CERTO** |
| Câmara julga definitivamente crime comum | **ERRADO** |
| crime comum → STF | **CERTO** |
| responsabilidade → Senado | **CERTO** |
| 180 dias encerram o processo | **ERRADO** |
| inabilitação constitucional = 8 anos | **CERTO** |

## 25. Fluxo de resolução

```text
1. Investidura/sucessão?
   → 77–83

2. Competência presidencial?
   → 84
   → é delegável?

3. Decreto?
   → IV ou VI?

4. Responsabilidade?
   → 85 categoria
   → 86 fluxo

5. Quem atua?
   → Câmara admite
   → STF julga comum
   → Senado julga responsabilidade

6. Número?
   → 10 / 90 / 30 / 15 / 60 / 180 / 8
```
