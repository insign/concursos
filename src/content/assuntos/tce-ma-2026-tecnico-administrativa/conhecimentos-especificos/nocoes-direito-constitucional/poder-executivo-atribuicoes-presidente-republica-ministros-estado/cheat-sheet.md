# Poder Executivo — recuperação rápida

## 1. Mapa mínimo

```text
76 → Presidente exerce Executivo + Ministros auxiliam
84 → atribuições PRIVATIVAS do Presidente
87 → requisitos + atribuições dos Ministros
88 → criação/extinção de Ministérios e órgãos por LEI
```

## 2. Presidente × Ministro

| Ponto | Presidente | Ministro |
|---|---|---|
| posição | exerce o Executivo | auxilia |
| administração | direção superior federal | orientação + coordenação + supervisão setorial |
| norma administrativa | decreto/regulamento | instrução |
| prestação anual | contas ao Congresso | relatório ao Presidente |
| delegação | delega nos limites do art. 84, p.u. | pode receber |

## 3. Art. 84 — blocos

```text
I-II      → Ministros + direção superior
III-VI    → processo legislativo + decretos + veto
VII-VIII  → relações exteriores + tratados
IX-X      → defesa/sítio + intervenção
XI        → mensagem + plano de governo
XII       → indulto + comutação
XIII      → Forças Armadas
XIV-XVIII → nomeações + Conselhos
XIX-XXII  → guerra + paz + distinções + forças estrangeiras
XXIII-IV  → PPA/LDO/orçamento + contas
XXV       → cargos federais
XXVI      → medida provisória
XXVII     → outras atribuições constitucionais
XXVIII    → propõe calamidade nacional
```

## 4. Delegação — decore

```text
DELEGÁVEIS
VI
XII
XXV — 1ª PARTE
```

Tradução:

```text
VI  → decreto constitucional
XII → indulto + comutação
XXV → PROVER cargos federais
```

Delegatários:

```text
MINISTRO DE ESTADO
PGR
AGU
```

Não entram: veto, medida provisória, tratados, guerra, nomeação de Ministro do STF.

## 5. Decreto do art. 84

```text
IV → regulamento para FIEL EXECUÇÃO DA LEI
```

```text
VI, a → organização/funcionamento
         sem aumento de despesa
         sem criar órgão
         sem extinguir órgão

VI, b → extinguir função/cargo
         SOMENTE se VAGO
```

## 6. Relações exteriores

```text
VII  → relações com Estados estrangeiros + diplomatas
VIII → tratados/convenções/atos internacionais
       sujeitos a REFERENDO DO CONGRESSO
```

## 7. Defesa e crise

```text
IX    → estado de defesa + sítio
X     → intervenção federal
XIII  → comando supremo Forças Armadas
XIX   → guerra + mobilização
XX    → paz
XXII  → forças estrangeiras
XXVIII→ propõe calamidade nacional ao Congresso
```

## 8. Congresso + orçamento

```text
XI → mensagem + plano de governo

XXIII → PPA + LDO + propostas de orçamento

XXIV → CONTAS
       Congresso Nacional
       60 dias após abertura da sessão
       exercício anterior
```

## 9. Nomeações — contraste

### Com aprovação do Senado — XIV

```text
STF + Tribunais Superiores
Governadores de Territórios
PGR
presidente + diretores do Banco Central
outros servidores quando lei exigir
```

### Outros incisos

```text
XV   → Ministros do TCU, observado art. 73
XVI  → magistrados + AGU
XVII → membros do Conselho da República
```

`NEM TODA NOMEAÇÃO PRESIDENCIAL EXIGE SENADO`

## 10. Ministros — requisitos

```text
BRASILEIRO
+ MAIOR DE 21 ANOS
+ DIREITOS POLÍTICOS EM EXERCÍCIO
```

Não exige no art. 87:

```text
brasileiro nato
35 anos
nível superior
aprovação do Senado
```

## 11. Art. 87 — quatro núcleos

```text
I   → ORIENTA + COORDENA + SUPERVISIONA
      órgãos/entidades da área
      + REFERENDA atos/decretos do Presidente

II  → expede INSTRUÇÕES
      para executar leis + decretos + regulamentos

III → RELATÓRIO ANUAL de gestão
      ao PRESIDENTE

IV  → pratica atos de atribuições
      OUTORGADAS ou DELEGADAS pelo Presidente
```

Mnemônico:

```text
OCSR → Orienta / Coordena / Supervisiona / Referenda
IERD → Instruções / Execução / Relatório / Delegação
```

## 12. Relatório × contas

| Quem | O quê | Para quem | Prazo |
|---|---|---|---|
| Ministro | relatório de gestão | Presidente | anual |
| Presidente | contas do exercício anterior | Congresso | 60 dias após abertura da sessão |

## 13. Art. 87, IV × art. 84, p.u.

```text
87, IV
→ Ministro pratica atos outorgados/delegados

NÃO significa
→ todas as competências presidenciais podem ser delegadas

84, p.u.
→ limita delegação do art. 84 a VI + XII + XXV(1ª)
```

## 14. Art. 88

```text
CRIAR/EXTINGUIR MINISTÉRIO OU ÓRGÃO
→ LEI
```

Contraste:

```text
84, VI → decreto NÃO cria nem extingue órgão
88     → lei dispõe sobre criação/extinção
```

## 15. Pegadinhas A–E

| Afirmação | Julgamento |
|---|---|
| Ministros exercem o Executivo junto com o Presidente | **ERRADO** |
| Presidente nomeia e exonera Ministros | **CERTO** |
| Toda competência do art. 84 é indelegável | **ERRADO** |
| Veto é delegável | **ERRADO** |
| Indulto é delegável | **CERTO** |
| Prover cargo federal pode ser delegado | **CERTO** |
| Decreto do VI pode criar órgão sem despesa | **ERRADO** |
| Decreto do VI pode extinguir cargo ocupado | **ERRADO** |
| Ministro precisa ser brasileiro nato | **ERRADO** |
| Ministro deve ser maior de 21 anos | **CERTO** |
| Ministro expede instruções para executar regulamentos | **CERTO** |
| Ministro envia seu relatório anual ao Congresso | **ERRADO** |
| Art. 87, IV permite delegar qualquer competência presidencial | **ERRADO** |
| Criação de Ministério depende de lei | **CERTO** |

## 16. Números e palavras-chave

| Tema | Chave |
|---|---|
| idade de Ministro | **maior de 21 anos** |
| contas presidenciais | **60 dias** |
| delegáveis | **VI + XII + XXV(1ª)** |
| art. 87, I | **orientação + coordenação + supervisão + referendo** |
| art. 87, III | **relatório anual → Presidente** |

## 17. Fluxo de resolução

```text
1. Quem pratica o ato?
   → Presidente ou Ministro?

2. Se Presidente:
   → qual inciso do art. 84?
   → é delegável?

3. Se decreto:
   → IV (fiel execução da lei)
   → ou VI (hipóteses constitucionais)?

4. Se Ministro:
   → requisito do caput?
   → I, II, III ou IV do art. 87?

5. Se delegação ministerial:
   → conferir também o limite do art. 84, p.u.

6. Se criação/extinção de Ministério/órgão:
   → art. 88 → LEI
```
