# Redação dissertativa — mapa de revisão do Generalista

**Comando → recorte → ideia central → duas razões diferentes → conclusão sustentada → conferência da folha.** Se o comando pedir explicar, desenvolva mecanismos; se pedir discutir uma posição, sustente a tese. Quatro parágrafos são apenas uma forma possível.

## Regras do edital — sem importar outro exame

| Dimensão | Recuperar |
|---|---|
| Prova | redação dissertativa, **até 30 linhas**, **20 pontos** |
| Tema | **conhecimentos gerais, Grupo I**; não há disciplina autônoma de Atualidades |
| Aprovação | nota final **≥ 10**; cinco horas compartilhadas com a objetiva |
| Conteúdo | apresentação, estrutura e desenvolvimento do tema; máximo **20** |
| Língua | erros de grafia, morfossintaxe e propriedade vocabular são descontados |
| Folha | somente a definitiva é avaliada; rascunho facultativo; sem substituição por erro |
| Forma | manuscrito legível, caneta preta de material transparente; exceções mediante atendimento deferido |
| Anulação | marca de identificação indevida ou não devolução do documento definitivo |

A discursiva só é corrigida para os habilitados pela objetiva e pelos limites classificatórios. **Não são requisitos expressos:** título obrigatório, mínimo de linhas, citação de autoridade, quatro parágrafos fixos ou proposta de intervenção de outro exame.

### Nota final e dupla correção

\[
\mathrm{NPD}=\mathrm{NC}-4\times\frac{\mathrm{NE}}{\mathrm{TL}}.
\]

<abbr title="Nota na Prova Discursiva">NPD</abbr> = nota final; <abbr title="Nota de Conteúdo">NC</abbr> = conteúdo; <abbr title="Número de Erros">NE</abbr> = erros; <abbr title="Total de Linhas efetivamente escritas">TL</abbr> = linhas efetivas. Resultado negativo vira zero; **fuga ao tema ou ausência de texto = zero por regra própria**. Exemplo autoral: conteúdo 16, seis erros e 24 linhas → **15 pontos**.

Duas notas de conteúdo convergem quando a diferença é **no máximo cinco pontos** (25% de 20): calcula-se a média. Diferença maior exige terceira correção, utilizando as duas avaliações mais próximas **desde que convergentes**.

**Recurso:** impugnação ao padrão preliminar pode alterá-lo para todos; após padrão definitivo, recurso ao resultado provisório discute a correção aplicada ao texto, não o padrão em tese.

## A diferença entre melhorar a forma e melhorar a resposta

| Defeito | Pergunta da revisão |
|---|---|
| Tema sem resposta | qual posição ou explicação o verbo do comando exige? |
| Argumento genérico | qual mecanismo explica a ideia? |
| Repetição entre desenvolvimentos | o segundo acrescenta condição, limite ou comparação nova? |
| “Portanto” sem consequência lógica | a conclusão decorre das premissas? |
| “Isso/ele” ambíguo | qual termo preciso deve reaparecer? |
| Depois → porque | atribuí uma causa sem evidência? |
| Pode → sempre | aumentei indevidamente certeza ou alcance? |
| Dados ou citações sem fonte | posso usar explicação ou hipótese explicitamente identificada? |
| Fecho com assunto inédito | esse ponto precisa entrar antes ou ser cortado? |
| Mais de 30 linhas | eliminei repetição antes de cortar argumento essencial? |

**Checklist final:** comando cumprido, tema delimitado, ideia central clara, duas razões efetivamente desenvolvidas, encadeamento lógico, linguagem formal sem rebuscamento, concordância e pontuação revistas, texto dentro das 30 linhas, sem identificação indevida, folha definitiva devolvida.
