# Significação e substituição lexical — revisão

**Dois filtros:** a troca cabe na frase completa? Mantém o sentido, a referência e os efeitos exigidos pelo comando? Mesma classe gramatical ou entrada no dicionário não basta.

## Relações e contexto

| Pista | Recuperação |
| --- | --- |
| <abbr title="sentido de uma palavra selecionado pelo contexto">Acepção</abbr> | Falha grave = séria; nota grave = frequência baixa. |
| <abbr title="proximidade ou igualdade de sentido em determinado uso">Sinonímia</abbr> | Conferir sentido, intensidade, avaliação e tom. Curto não garante conciso. |
| <abbr title="oposição de sentidos que admite graus intermediários">Antonímia gradual</abbr> | Não quente pode ser morno; não implica frio. |
| <abbr title="oposição de perspectivas sobre a mesma relação">Oposição conversiva</abbr> | Ana compra de Luís ↔ Luís vende a Ana; reorganizar participantes. |
| <abbr title="termo de sentido mais amplo">Hiperônimo</abbr> / <abbr title="termo de sentido mais específico">hipônimo</abbr> | Automóvel → veículo perde especificidade isoladamente. Na retomada “um automóvel… o veículo”, o contexto pode conservar a identificação. |
| Parte / todo | Página não é espécie de relatório; enviar a página não garante enviar o todo. |
| <abbr title="conjunto de significados associados a uma área">Campo semântico</abbr> | Exame e relatório podem compartilhar tema sem serem sinônimos. |
| <abbr title="sentidos relacionados de uma mesma palavra">Polissemia</abbr> / <abbr title="coincidência formal entre palavras de sentidos independentes">homonímia</abbr> | Cabeça do corpo/equipe; manga da camisa/fruta. Duas definições não resolvem a classificação sozinhas. |
| <abbr title="semelhança de forma entre palavras diferentes">Paronímia</abbr> | Ratificar = confirmar; retificar = corrigir. Eminente = ilustre; iminente = prestes a ocorrer. |

**Mesmo objeto, outro efeito:** “o carro” e “a lata enferrujada” podem apontar para o mesmo veículo e mudar a avaliação. “Essa hipótese” → “esse fato” apresenta como estabelecida uma possibilidade.

## Inferências e precisão

- **<abbr title="conclusão que decorre necessariamente da verdade de uma afirmação">Acarretamento</abbr>:** conseguiu concluir → concluiu; tentou concluir não garante êxito. Não chamar a conclusão de pressuposto: “não conseguiu concluir” já não a garante.
- **<abbr title="informação apresentada como já estabelecida no contexto">Pressuposição</abbr>:** voltou a assinar toma como dada uma assinatura anterior, normalmente mantida em “não voltou” ou “voltou?”. Não fixa a duração de um intervalo. Descobriu/lamentou que X normalmente tomam X como fato; suspeitou não.
- **<abbr title="inferência contextual que pode ser cancelada">Implicatura</abbr>:** alguns costuma sugerir não todos; na leitura inclusiva, “alguns, talvez todos” é compatível. “Alguns, mas não todos” exclui a totalidade expressamente.
- **<abbr title="presença de mais de uma interpretação plausível">Ambiguidade</abbr>:** “sua equipe” pode ter mais de um antecedente. **<abbr title="imprecisão dos limites de uma expressão">Vagueza</abbr>:** recentemente não equivale a exatamente dois dias. **<abbr title="ausência de detalhes sem exigir interpretações rivais">Subespecificação</abbr>:** providências não informa quais.
- **<abbr title="cenário em que uma formulação é verdadeira e a outra é falsa">Contraexemplo</abbr>:** tentativa seguida de fracasso separa tentou de concluiu.

## Palavras pequenas, mudanças grandes

| Expressão | Informação a preservar |
| --- | --- |
| pode / deve | Contexto: possibilidade, capacidade ou permissão; obrigação ou conclusão provável. |
| afirmou / sugere / confirmou | Fonte e força da informação. |
| começou / vem fazendo / fez | Início / continuidade ou repetição / acontecimento realizado. Começar não garante concluir. |
| já / ainda não | Ocorrência / não ocorrência até o ponto relevante; expectativa depende do contexto. |
| ao menos / mais de 30 | 30 ou mais / acima de 30, excluindo 30. |
| até / exatamente 30 | Teto 30 / valor fixo 30. |
| cerca de 30 | Aproximação; sem margem numérica fixa dada pela expressão. |
| nem todos / nenhum | Ao menos um não fez / zero fizeram. Nem todos não garante que algum fez. |
| só Ana / Ana revisou só o relatório | Restringe pessoa / objeto. “Ana só revisou…” requer contexto para resolver o alcance. |
| principalmente / inclusive | Prioridade ou concentração / inclusão. |
| porque / se | Causa afirmada / condição; não são equivalentes. |
| embora / mas | Podem manter expectativa contrariada com ajuste da construção. |

**Gramática e expressão inteira:** assistiu ao evento → viu o evento; há documentos → existem documentos; levou em conta → considerou; deu conta da demanda → conseguiu atendê-la. Não conservar automaticamente preposições ou trocar uma palavra isolada de expressão fixa.

**Fechamento:** releia o parágrafo, compare participantes, tempo, certeza, quantidade, condições e tom. Uma troca pode ser correta e alterar o sentido; outra pode mudar a forma e conservar o que foi exigido.
