# Verbo como classe de palavras

**Forma → sentido → construção.** Conjugação, regularidade, predicação, auxiliaridade e voz são critérios independentes. Exemplos hipotéticos.

## Forma e classificação

**Cantávamos = cant- + -a- + -va- + -mos:** radical (significado), vogal temática (conjugação), desinência modo-temporal, desinência número-pessoal. Tema = radical + vogal temática; nem toda forma permite separar todas as partes.

| Critério | Recuperação |
|---|---|
| Conjugação | -ar: primeira; -er: segunda; -ir: terceira; pôr e derivados pertencem à segunda |
| Tonicidade | Rizotônica: acento no radical (canto); arrizotônica: fora dele (cantamos) |
| Regularidade | Regular segue paradigma; irregular altera radical/desinências; ser/ir são exemplos estáveis de anômalos |
| Defectividade | Lacunas no paradigma tradicional; não significa ausência de sujeito; reaver não copia todas as formas de haver |
| Abundância | Formas equivalentes, sobretudo no particípio: aceitado/aceito |

## Formas nominais

- **Infinitivo** nomeia: analisar. Pode ser pessoal sem marca visível: é preciso **eu estudar**.
- **Gerúndio** apresenta desenvolvimento, modo ou simultaneidade: revisando. “Amanhã, às dez, estarei revisando” pode ser legítimo; uma cadeia para mero envio futuro pode ser inadequada ao sentido pretendido.
- **Particípio** participa de tempo composto, passiva ou característica/estado: analisado/feito. Em tinha analisado, é invariável; em propostas foram analisadas, concorda com propostas.

| Infinitivo no contexto | Decisão |
|---|---|
| Sujeito próprio expresso antes da forma | antes **de os candidatos estudarem**; preserve de os na redação formal |
| Unidade com auxiliar e mesmo sujeito | devem estudar, nunca devem estudarem |
| Mesmo sujeito fora da locução | Pode haver opção de foco: saíram para estudar/estudarem |
| Percepção/causação com sujeito nominal | Pode haver alternância: vi os candidatos sair/saírem |
| Sujeito em pronome oblíquo nessa construção | vi-os sair, sem flexão |

Diferença de agentes e clareza favorecem flexão; **plural sozinho não a torna obrigatória**.

Preferência tradicional para particípios duplos: regular com ter/haver; irregular com ser/estar. **Pago, gasto, ganho, pego** também ocorrem com ter/haver. Use **chegado/trazido**, não chego/trago como particípios. Particípio irregular não equivale a verbo irregular: pedir/peço tem pedido regular.

## Predicação e auxiliaridade

| Emprego | Relação |
|---|---|
| revisou o texto | <abbr title="Verbo transitivo direto">VTD</abbr>: objeto direto |
| precisa de apoio | <abbr title="Verbo transitivo indireto">VTI</abbr>: objeto indireto |
| entregou o texto à chefia | <abbr title="Verbo transitivo direto e indireto">VTDI</abbr>: dois tipos de objeto |
| o bebê dormiu | <abbr title="Verbo intransitivo">VI</abbr>: sem objeto nesse uso |
| parece tranquila | <abbr title="Verbo de ligação">VL</abbr>: sujeito + predicativo |

“Escreveu o parecer” tem objeto; “escreve bem” pode ser intransitivo. Circunstância não é automaticamente objeto. **Assistir o paciente** (prestar assistência) e **assistir à sessão** (presenciar) diferem em sentido e predicação.

| Construção | Recuperação |
|---|---|
| havia estudado / estava estudando | Tempo composto / desenvolvimento; auxiliares concordam com o sujeito |
| estava cansada | Estar de ligação, com predicativo |
| deve/pode estudar | Obrigação/probabilidade; possibilidade/capacidade/permissão, conforme contexto |
| vai estudar; hão de estudar | Futuridade/intenção; proximidade não é necessária |
| vinham sendo revisados | Desenvolvimento + passiva; pessoa/número no primeiro auxiliar |
| deseja estudar | Não classificar automaticamente como locução: desejar pode reger oração reduzida |

## Voz passiva e valores de se

**A comissão aprovou as propostas → as propostas foram aprovadas pela comissão.** Objeto direto da ativa → sujeito paciente; ser preserva tempo/modo; auxiliar e particípio concordam com propostas; agente pode ser omitido.

Objeto direto é condição necessária para essa transformação, **mas não suficiente**: haver existencial não admite passiva. Sujeito de voz ativa também não precisa ser agente intencional.

| Construção/teste | Análise |
|---|---|
| Publicam-se relatórios → relatórios são publicados | Passiva sintética; sujeito paciente determina concordância |
| Precisa-se de apoio; vive-se bem | Indeterminação com <abbr title="Verbo transitivo indireto">VTI</abbr> ou <abbr title="Verbo intransitivo">VI</abbr>, no singular |
| Ela se feriu → a si mesma | Reflexivo |
| Colegas se cumprimentaram → uns aos outros | Recíproco na leitura mútua |
| arrependeu-se; queixou-se | Parte integrante de verbo pronominal |
| foi-se embora | Expletivo, retirável sem destruir a estrutura básica |
| se vier | Conjunção condicional |

Passiva sintética normalmente usa <abbr title="Verbo transitivo direto">VTD</abbr> ou <abbr title="Verbo transitivo direto e indireto">VTDI</abbr>, **mas a etiqueta não decide**: ela se feriu é reflexiva. **Têm-se publicado relatórios:** auxiliar no plural. Foi aprovado não equivale a era aprovado.

**Foi assinado** focaliza evento; **está assinado** pode focalizar estado resultante. “Caso difícil de resolver” admite leitura passiva; **de + infinitivo não é sempre passiva**.

## Impessoalidade

| Construção | Sujeito e concordância |
|---|---|
| há/houve recursos; há dois anos | Haver existencial/temporal: sem sujeito, singular |
| faz dois anos; fez calor | Fazer temporal/climático: sem sujeito, singular |
| choveu / choveram pedidos | Fenômeno literal impessoal / uso figurado pessoal |
| deve haver alternativas; pode fazer meses | Impessoalidade do principal alcança auxiliar |
| existem/devem existir alternativas | Existir pessoal: alternativas é sujeito |
| candidatos haviam estudado; hão de estudar | Haver auxiliar pessoal; diferente de há de haver alternativas |
| candidatos houveram por bem recorrer | Haver por bem pessoal |
| é uma hora; são duas horas | Ser tem concordância especial em horas/distâncias; não estender a haver |
| os cães latiram | Unipessoal típico com sujeito e terceira pessoa plural |

**Sujeito indeterminado existe, mas não está identificado; oração sem sujeito tem verbo impessoal.** Ter existencial é corrente na fala; na redação formal, prefira haver/existir conforme o contexto. Ter com sujeito possuidor é outro emprego.

**Para reescrever:** localize sujeito e objetos; teste passiva/reflexividade/reciprocidade; confira sentido, auxiliar, flexão e preservação do acontecimento.
