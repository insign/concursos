# Coesão textual — mapa de recuperação

**Continuidade + progressão:** manter o fio e acrescentar informação. Coesão liga partes; coerência permite construir sentido global. Pronome ou conector não garante coerência.

## 1. Referentes e direção

| Operação | Controle |
| --- | --- |
| Introdução | objeto apresentado pela primeira vez |
| Retomada/correferência | expressões apontam para o mesmo objeto |
| Recategorização | novo nome mantém referente e destaca perspectiva |
| Anáfora direta | retoma objeto anterior |
| Anáfora indireta | novo referente associado a uma âncora: prédio → recepção |
| Catáfora | conteúdo especificado depois: `Isto é essencial: preservar as provas` |
| Exófora | depende da situação externa: `deixe estes documentos ali` |

**Referente:** entidade/conteúdo acompanhado. **Antecedente:** expressão textual usada como pista. Não são sinônimos. Proximidade não decide: `ela` pode retomar auditora ou diretora; `seu relatório` pode ter duas possuidoras.

Demonstrativos podem retomar, antecipar ou apontar para fora. Não automatizar `este = catáfora`, `esse = anáfora`. `O mesmo relatório` tende à identidade; `outro relatório` tende a novo exemplar.

## 2. Substituir, repetir, omitir e resumir

| Recurso | Exemplo/gatilho |
| --- | --- |
| Referência | o parecer → ele |
| Substituição nominal | uma cópia do parecer → você tem uma? |
| Substituição verbal | revisou os autos → também o fez |
| Elipse | uma unidade analisou contratos; a outra, convênios |
| Coesão lexical | repetição funcional, palavras relacionadas, geral/específico |
| Encapsulamento | `isso`, `essa decisão`, `diante desse quadro` resumem uma porção de texto |
| Nominalização | decidiu → a decisão; conferir agente, tempo e modo de apresentar a ação |

**Precisão:** repetição é melhor que pronome ambíguo. Hiperônimo é mais geral (`documento`); hipônimo é mais específico (`contrato`). Trocar geral por específico pode acrescentar informação não autorizada. `Ocorrência`, `irregularidade` e `fraude` não classificam o fato da mesma maneira.

## 3. Relativos: retomada e ligação

**Delimitar oração → propor antecedente → reconstruir → conferir função, concordância e regência.**

- `Regiões de clima diverso que exigem soluções`: reconstruir `regiões exigem`; o mais próximo não vence automaticamente.
- `Procedimento ao qual aderiu`: `aderir a` determina a preposição.
- `Empresa cujo contrato`: posse; `cujo` concorda com `contrato`, sem artigo após ele.
- `Setor onde ocorreu`: lugar; referente não locativo pede em geral `em que`/`no qual`.

## 4. Conectores: relação no contexto

| Relação | Marcas frequentes |
| --- | --- |
| Adição | e, também, além disso, bem como, não só... como também |
| Alternância | ou... ou, ora... ora |
| Oposição | mas, porém, contudo, entretanto |
| Concessão | embora, ainda que, mesmo assim, apesar de |
| Causa/justificativa | porque, já que, visto que, dado que, pois, como |
| Consequência/conclusão | por isso, de modo que, portanto, logo, assim |
| Condição/finalidade | se, caso, desde que; para que, a fim de que |
| Tempo/proporção | quando, em seguida; à medida que, quanto mais... mais |
| Comparação/conformidade | como, assim como; conforme, segundo |

**Causa:** razão do fato. **Justificativa:** fundamento da afirmação/ordem. **Consequência:** efeito. **Conclusão:** resultado de raciocínio.

`Mas` coordena; `embora` introduz circunstância concessiva e normalmente exige subjuntivo. Preservar contraste não dispensa ajustar construção, verbo e pontuação.

`Pois` explicativo: “reveja o ato, pois ele contém vício”. Conclusivo: “o ato contém vício; deverá, pois, ser revisto”. Posição ajuda; relação confirma. `E`, `como`, `já`, `assim` e `então` têm valores contextuais: não escolher pelo rótulo isolado.

## 5. Alcance e progressão

- A forma pode ligar termos, orações, períodos ou vários parágrafos. Explicite a paráfrase inteira antes de escolher o referente.
- Sequenciação: `inicialmente/em seguida/por fim`; `acima/no quadro seguinte`; `quanto a/em síntese/por outro lado`.
- Paralelismo: membros equivalentes em forma reconhecível — `reduzir despesas, ampliar controles, revisar contratos`.
- **Tema constante:** mesmo tópico, informações novas. **Linear:** informação nova vira tópico seguinte. **Derivado:** tópico geral se desdobra em subtópicos.

**Antes de aceitar reescrita:** ler entorno → localizar unidades ligadas → explicitar referente/relação → conferir forma final → comparar sentido, alcance e foco → conferir progressão global.
