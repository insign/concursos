# Ortografia oficial — decisões de revisão

**Fenômeno → estrutura → regra → exceção/variante → conferir todas as formas.** Som ou analogia não decide todo registro.

## 1. Acentuação

| Posição | Regra de recuperação |
| --- | --- |
| Monossílabo tônico | `a(s)`, `e(s)`, `o(s)`; ditongos abertos `éi`, `éu`, `ói` |
| Oxítona: última sílaba forte | `a(s)`, `e(s)`, `o(s)`, `em`, `ens`; ditongos abertos |
| Paroxítona: penúltima | terminações como `l`, `n`, `r`, `x`, `ps`, `i(s)`, `us`, `um/uns`, `ã(s)`, `ão(s)`, ditongo oral |
| Proparoxítona: antepenúltima | todas |
| Hiato com `i/u` | tônico, depois de vogal, sozinho ou com `s`; observar exceções |

**Hiato:** `país`, `saída`, `baú`, `juízes`. **Sem acento:** `rainha`, `moinho` (antes de `nh`); `juiz`, `raiz`, `ruim` (com outra consoante na sílaba); `feiura`, `baiuca` (paroxítona depois de ditongo). **Oxítonas mantêm:** `Piauí`, `teiú`, `tuiuiú`.

| Retirado | Mantido ou permitido |
| --- | --- |
| `ideia`, `heroico`, `assembleia`, `jiboia` | `herói`, `papéis`, `chapéu` |
| `voo`, `enjoo`; `creem`, `deem`, `leem`, `veem` | `pôde/pode`; `pôr/por` |
| `para`, `pela(s)`, `pelo(s)`, `polo(s)` | `tem/têm`, `vem/vêm`, `mantém/mantêm` |
| trema em palavras portuguesas | estrangeiros/derivados: `Müller`, `mülleriano` |

Facultativos: `forma/fôrma`, `demos/dêmos`. `História` e `série`: ditongo crescente na análise usual; proparoxítonas aparentes na descrição do Acordo. A grafia não muda.

`Arguo`, `argui`, `arguem`, `argua`: sem acento no `u`. `Averiguo/averíguo`, `enxagua/enxágua`: pronúncias admitidas. Derivação exige nova análise: `país → paisinho`, `avô → avozinho`; preserve base: `raiz → raizinha`.

## 2. Hífen

| Formação | Decisão |
| --- | --- |
| prefixo em vogal + mesma vogal | `micro-ondas`, `anti-inflamatório` |
| vogais diferentes | `autoescola`, `antiaéreo`, `infraestrutura` |
| vogal + `r/s` | duplicar: `antirracista`, `antissocial`, `ultrassom` |
| antes de `h` | hífen em regra: `anti-higiênico`; aglutinações registradas: `desumano`, `reabilitar` |
| `co-`, `re-`, `pre-` átono | `coobrigação`, `reeleição`, `preexistente` |
| `ex-`, `vice-`, `sem-`, `além-`, `aquém-`, `recém-` | hífen |
| `pré-`, `pós-`, `pró-` tônicos | `pré-escolar`, `pós-graduação`, `pró-reitor` |
| `pan-/circum-` | hífen antes de vogal, `m`, `n` ou `h` |
| `hiper-/inter-/super-` + `r` | `inter-racial`, `super-resistente` |

- **Bem/mal:** `bem-estar`, `mal-estar`, `bem-vindo`; registrados: `benfeito`, `benfeitor`, `malcriado`. `Benfeito` pode ser benefício; `bem-feito` qualifica; `bem feito` é combinação livre.
- **Compostos:** `guarda-chuva`, `arco-íris`; aglutinados: `paraquedas`, `paraquedista`, `girassol`. Não estender: `para-brisa`, `para-choque`, `para-lama`.
- **Locuções:** normalmente sem hífen; exceções `cor-de-rosa`, `pé-de-meia`, `mais-que-perfeito`, `ao deus-dará`, `à queima-roupa`.
- Espécies: `erva-doce`, `cobra-d'água`, `bem-te-vi`. Pronome depois/dentro do verbo: `entregou-lhe`, `fazê-lo`, `dar-se-á`.

## 3. Letras, sentido e porquês

26 letras, incluindo `k/w/y`; `ç` não é letra adicional. Antes de `p/b`, normalmente `m`. Entre vogais: `rr` forte, `ss` surdo. Famílias: `análise/analisar`, `pesquisa/pesquisar`; `-ez/-eza`, `-izar` não justificam analogia universal.

`Sessão` reunião; `seção` divisão; `cessão` ceder. `Ratificar` confirmar; `retificar` corrigir. `Eminente` destacado; `iminente` prestes a ocorrer. `Infringir` violar; `infligir` aplicar pena. `Cumprimento` saudação/execução; `comprimento` extensão.

| Forma | Função |
| --- | --- |
| `por que` | pergunta direta/indireta; `pelo qual`; preposição `por` + oração introduzida por `que` |
| `por quê` | razão interrogada antes de pausa: `mudou por quê?` |
| `porque` | causa/explicação; também finalidade em construção menos frequente |
| `porquê` | substantivo: `o porquê`, `os porquês` |

## 4. Convenções e consulta

- Minúscula: dias, meses, estações, idioma, cargo comum. Maiúscula: nome próprio/institucional, região como nome (`Nordeste`). Disciplina e uso reverencial podem admitir opção.
- Apóstrofo restrito: `d'Os Lusíadas`, `Sant'Ana`, `cobra-d'água`; uso comum `dele`, `numa`. Sujeito de infinitivo: `apesar de o servidor ter chegado`.
- Abreviatura normalmente com ponto: `pág.`, `etc.`; sigla normalmente sem pontos; plural com `s`, sem apóstrofo; símbolo invariável: `5 kg`, `10 km`, `20 kW`.
- Variante admitida não autoriza improviso. Consulte o **<abbr title="Vocabulário Ortográfico da Língua Portuguesa">VOLP</abbr>** para registros e casos não decididos pela regra.
