# Arquivamento e ordenação — revisão rápida

**Operações diferentes:** classificação = função/atividade; **ordenação** = sequência dentro do conjunto; **arquivamento** = guarda ordenada/controle, também ato de determinar guarda após cessar tramitação.

**Mapa:** conjunto certo → chave de ordenação → unidade identificada → localização → retirada e retorno controlados. Não desfaça ordem original e vínculos só para mudar a chave.

## Chave e método

| Pista | Método |
|---|---|
| Nome/sobrenome | Alfabético; usar convenção para nomes compostos e homônimos |
| Cidade/território | Geográfico; definir chave secundária |
| Número da pasta | Numérico simples |
| Número **e** data dos documentos | Numérico-cronológico |
| Só datas | Cronológico |
| Assuntos | Temático/ideográfico |
| Temas em lista alfabética única | Dicionário |
| Temas sob categorias gerais | Enciclopédico |
| Classes numeradas e subdivididas com **traços** | <abbr title="Método numérico de ordenação por assunto com classes e subclasses ligadas por traços">Duplex</abbr> |
| Dez grandes classes, subdivisões sucessivas | Decimal |
| Grupos de números lidos da direita para a esquerda | Dígito-terminal |
| Fonética, não escrita do nome | <abbr title="Método de ordenação pela pronúncia dos nomes">Soundex</abbr> |
| Cores representando letras | <abbr title="Método de ordenação alfabética com cores">Variadex</abbr> |
| Letras + números | Alfanumérico |

**Direto:** chave conhecida leva à sequência de guarda. **Indireto:** exige índice/código de correspondência antes (nome → número da pasta). Número isolado não assegura localização se a referência não estiver registrada.

## Não confundir

- Arquivamento **não é eliminação** nem recolhimento permanente.
- Numérico simples ≠ numérico-cronológico; número de **pasta** ≠ número **e data de documento**.
- **Horizontal/vertical:** posição física de guarda, não chave de ordenação.
- **Empréstimo para consulta** ≠ **desarquivamento para retomar a ação**, na distinção do Guia do Arquivo Nacional de 2025.
- Guardar arquivo digital em pasta genérica ≠ gestão arquivística com vínculos e recuperação.
- Guia federal orienta o Executivo federal; seus procedimentos não são automaticamente exigíveis no Maranhão.

**Caso âncora:** pastas 108 João, 109 Bruno, 110 Ana. Consulta “Bruno Lima” com arquivo numérico → índice “LIMA, Bruno → 109” → buscar 109 → registrar retirada → devolver no lugar 109.
