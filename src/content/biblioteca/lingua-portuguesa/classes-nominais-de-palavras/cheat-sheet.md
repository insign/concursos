# Classes nominais de palavras

## Regra de ouro

**Classe gramatical, função sintática e sentido são planos diferentes.** Analise a palavra na oração: a mesma forma pode mudar de classe conforme o emprego.

Classes deste assunto: **substantivo, artigo, adjetivo, numeral e pronome**. Ser classe tradicionalmente variável não significa que toda forma varie: `mil`, `isto`, `alguém`, `ninguém` e `quem` são invariáveis.

## Formas que mudam de leitura

| Forma | Contraste útil |
| --- | --- |
| `um/uma` | artigo: `um candidato`; numeral: `um, não dois` |
| `o/a/os/as` | artigo: `o relatório`; oblíquo: `eu o li`; demonstrativo: `o que ocorreu` |
| `meio` | numeral: `meia hora`; substantivo: `meio de transporte`; advérbio: `meio cansada` |
| `brasileiro` | adjetivo: `cidadão brasileiro`; substantivo: `o brasileiro` |
| `certo` | indefinido: `certo candidato`; adjetivo: `candidato certo` |
| `todo` | `todo país` = qualquer; `todo o país` = país inteiro |
| `bastante` | `bastantes recursos` = muitos; `recursos bastantes` = suficientes; `bastante atentos` = muito |

### `o/a/os/as`

| Exemplo | Classe |
| --- | --- |
| `A ata foi aprovada.` | artigo |
| `A comissão a aprovou.` | pronome pessoal oblíquo |
| `Escolhi a de menor custo.` | pronome demonstrativo = aquela |
| `Não entendi o que ocorreu.` | `o` demonstrativo; `que` relativo |

Em `o que deu lugar à figura`, **`que`**, e não `o`, exerce a função sintática na oração relativa.

## Substantivo

| Critério | Classificações |
| --- | --- |
| extensão | comum / próprio |
| natureza | concreto / abstrato |
| formação | primitivo / derivado |
| estrutura | simples / composto |
| coletividade | coletivo |
| gênero | comum de dois / sobrecomum / epiceno |

- **Concreto** não significa palpável: `anjo` é tradicionalmente concreto.
- **Coletivo** tem forma singular: `o elenco chegou`.
- **Comum de dois:** mesma forma; artigo distingue — `o/a estudante`.
- **Sobrecomum:** um gênero gramatical para pessoa de qualquer sexo — `a vítima`, `o cônjuge`.
- **Epiceno:** nome de animal com um gênero; sexo indicado por `macho/fêmea` — `a cobra macho`.
- Aumentativo/diminutivo podem expressar tamanho, afeto, ironia ou depreciação.
- <abbr title="Passagem de outra classe a emprego de substantivo">Substantivação</abbr>: `o belo`, `seu não`, `um porquê`.

### Plural dos compostos

| Estrutura | Tendência | Exemplo |
| --- | --- | --- |
| elementos variáveis autônomos | variam os variáveis | `couves-flores`, `cirurgiões-dentistas` |
| elemento invariável + nome | varia o nome | `guarda-chuvas`, `vice-presidentes` |
| ligação por preposição | varia o primeiro | `pés de moleque` |
| repetição/onomatopeia | varia o segundo | `reco-recos` |
| segundo termo especifica o primeiro | pode variar só o primeiro | `palavras-chave`, `salários-família` |

**Não absolutize:** `palavras-chaves` também é variante admitida.

## Artigo

| Tipo | Formas | Efeito central |
| --- | --- | --- |
| definido | `o, a, os, as` | apresenta referente identificável/delimitado |
| indefinido | `um, uma, uns, umas` | apresenta referente não identificado ou pouco delimitado |

O artigo também produz efeitos contextuais sem mudar de classe:

- `uns vinte minutos` → aproximação;
- `umas desculpas!` → depreciação possível;
- `um padre Guedes` → apresentação vaga/indefinida;
- `a servidora levantou a mão` → artigo definido com valor possessivo contextual.

Trocar `um` por `o`, retirar artigo ou acrescentá-lo pode alterar a referência.

## Adjetivo

- **Qualificativo:** atribui qualidade — `decisão justa`.
- **Relacional:** liga a um campo — `controle financeiro`.
- Uniforme: `servidor/servidora competente`.
- Biforme: `servidor atento / servidora atenta`.
- <abbr title="Adjetivo que indica origem ou procedência">Gentílico</abbr>: `maranhense`, `brasileiro`.
- <abbr title="Grupo de palavras que caracteriza um nome">Locução adjetiva</abbr>: `amor de mãe`, `decisão de governo`.

| Posição | Leitura frequente |
| --- | --- |
| `grande homem / homem grande` | notável / de grande porte |
| `velho amigo / amigo velho` | de longa data / idoso |
| `pobre homem / homem pobre` | digno de pena / sem recursos |
| `certo candidato / candidato certo` | algum / adequado |

A posição **pode**, mas não precisa, mudar o sentido: `unanimidade total / total unanimidade` não produz automaticamente contraste relevante.

### Compostos e grau

- Regra geral do composto: varia o último — `acordos luso-brasileiros`.
- Exceção tradicional: `surdos-mudos`.
- Cor com substantivo: frequentemente invariável — `camisas verde-oliva`.

| Grau | Modelo |
| --- | --- |
| comparativo de igualdade | `tão útil quanto` |
| superioridade/inferioridade | `mais/menos útil que` |
| comparativo sintético | `melhor`, `pior`, `maior`, `menor` |
| superlativo absoluto | `muito útil`, `utilíssimo` |
| superlativo relativo | `o mais útil do grupo` |

## Numeral

| Classe | Ideia | Exemplos |
| --- | --- | --- |
| cardinal | quantidade | `um`, `dois`, `cem`, `mil` |
| ordinal | posição | `primeiro`, `vigésima` |
| multiplicativo | multiplicação | `dobro`, `triplo` |
| fracionário | parte do todo | `meio`, `terço` |

- `duzentas páginas`; `primeira etapa`.
- `dois mil candidatos`, mas `dois milhões`.
- `ambos/ambas` = os dois/as duas, na classificação tradicional.
- `enésima vez` = posição não especificada.
- `andar onze` pode usar cardinal para identificar posição.
- `um candidato, não dois` destaca quantidade: `um` é numeral, não artigo.

## Pronome

| Tipo | Exemplos / alerta |
| --- | --- |
| pessoal reto | `eu, tu, ele`; tipicamente sujeito |
| oblíquo átono | `me, te, o, a, lhe`; ligado ao verbo |
| oblíquo tônico | `mim, ti, si`; normalmente preposicionado |
| tratamento | concordância em 3ª pessoa: `Vossa Excelência decidiu` |
| possessivo | concorda com o possuído: `minhas decisões` |
| demonstrativo | `este, esse, aquele`; também `o/a/os/as` em certos usos |
| relativo | `que, quem, cujo, onde, o qual` |
| indefinido | `alguém, ninguém, qualquer`; plural `quaisquer` |
| interrogativo | `que, quem, qual, quanto` |

### Pessoais e tratamento

- `para eu redigir`: `eu` é sujeito do infinitivo.
- `para mim`: `mim` completa a preposição e não é sujeito de infinitivo.
- `O relatório foi redigido por mim` é correto: “praticar a ação” não é teste para escolher `eu/mim`.
- Reflexivo: `ela se observou` = a si mesma.
- Recíproco: `eles se cumprimentaram` = um ao outro.
- `Vossa Excelência`: ao falar com a pessoa; `Sua Excelência`: ao falar dela. Ambos exigem 3ª pessoa.

### Possessivos

Possessivo não indica apenas propriedade material:

- `suas calças` → propriedade material;
- `minha colega` → relação pessoal;
- `minha senhora` → deferência/respeito;
- `seus quarenta anos` → aproximação.

`Seu/sua` pode ser ambíguo. `O recurso de Pedro` fixa o possuidor; `o recurso dele` ainda pode ser ambíguo se houver mais de um referente masculino.

### Demonstrativos

- Retoma conteúdo anterior = **anáfora**.
- Anuncia conteúdo posterior = **catáfora**: `O problema é este: como resolver?`.
- `isto/isso/aquilo` são neutros, invariáveis e não acompanham diretamente substantivo expresso.
- Modelo tradicional entre **dois referentes já mencionados**: `aquele` retoma o primeiro; `este`, o último.
- Fora desse contraste específico, não transforme `este = catáfora` e `esse = anáfora` em regra absoluta.

### Indefinidos e relativos

- `todo país` ≠ `todo o país`.
- `qualquer` → plural `quaisquer`.
- `bastantes recursos` × `recursos bastantes` × `bastante atentos`.
- `recurso algum`, em construção negativa, equivale a nenhum.

Nos relativos, reconstrua a oração:

- `o assunto de que tratei` — preserve a <abbr title="Relação que determina o complemento e a preposição exigida">regência</abbr>;
- `a autora cujas obras li` — `cujo` indica posse, concorda com o termo seguinte e **não admite artigo**;
- `a cidade onde moro` — `onde` retoma lugar; para outros antecedentes, use a forma exigida pela regência;
- `a cidade aonde fui` — `aonde` quando a relação pede preposição `a`.

## Roteiro de prova

1. Leia toda a oração.
2. Pergunte: a palavra **nomeia, determina, caracteriza, quantifica, intensifica, substitui ou retoma**?
3. Separe classe, função sintática e valor de sentido.
4. Teste o contexto: `um` = apresentação ou contagem? `certo` = algum ou correto?
5. Confira gênero, número, grau, pessoa e invariabilidade.
6. Em compostos, identifique a classe e a relação entre os elementos.
7. Em artigos, possessivos e demonstrativos, preserve a referência e o valor contextual.
8. Nos relativos, reconstrua a oração e aplique a regência.
