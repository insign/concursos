# Classes nominais de palavras

## Regra de ouro

- Classe gramatical, sentido e função sintática são planos diferentes.
- Analise a palavra na oração: a mesma forma pode mudar de classe conforme o emprego.
- Classes deste assunto: substantivo, artigo, adjetivo, numeral e pronome.
- Classe tradicionalmente variável não significa que toda forma flexione: `mil`, `isto`, `alguém` e `quem` são invariáveis.

## Formas multifuncionais

| Forma | Empregos |
| --- | --- |
| `um/uma` | artigo: `um candidato`; numeral: `um, não dois` |
| `o/a/os/as` | artigo: `o relatório`; oblíquo: `eu o li`; demonstrativo: `o que ocorreu`, `a de menor custo` |
| `meio` | numeral: `meia hora`; substantivo: `meio de transporte`; advérbio: `meio cansada` |
| `brasileiro` | adjetivo: `cidadão brasileiro`; substantivo: `o brasileiro` |
| `certo` | indefinido: `certo candidato`; adjetivo: `candidato certo` |
| `todo` | `todo país` = qualquer; `todo o país` = país inteiro |
| `bastante` | `bastantes recursos`; `servidores bastante atentos` |

### `o/a/os/as`: três usos

| Exemplo | Classe |
| --- | --- |
| `A ata foi aprovada.` | artigo |
| `A comissão a aprovou.` | pronome pessoal oblíquo |
| `Escolhi a de menor custo.` | pronome demonstrativo = aquela |
| `Não entendi o que ocorreu.` | `o` demonstrativo; `que` relativo |

**Pegadinha:** em `o que deu lugar à figura`, `o` é demonstrativo, mas `que` exerce a função de sujeito da oração relativa.

## Substantivo

| Critério | Classificações |
| --- | --- |
| extensão | comum / próprio |
| natureza | concreto / abstrato |
| formação | primitivo / derivado |
| estrutura | simples / composto |
| coletividade | coletivo |
| gênero | comum de dois / sobrecomum / epiceno |

- Concreto não é sinônimo de palpável: `anjo` é tradicionalmente concreto.
- Coletivo tem forma singular: `o elenco chegou`.
- Comum de dois: `o/a estudante`.
- Sobrecomum: `a criança`, `a vítima`, `o cônjuge`.
- Epiceno: `a cobra macho/fêmea`.
- Diminutivo/aumentativo podem expressar afeto, ironia ou depreciação.
- Substantivação: `o belo`, `o não`, `um porquê`.

### Plural dos compostos

| Estrutura | Tendência | Exemplo |
| --- | --- | --- |
| elementos variáveis autônomos | variam os variáveis | `couves-flores`, `cirurgiões-dentistas` |
| elemento invariável + nome | varia o nome | `guarda-chuvas`, `vice-presidentes` |
| ligação por preposição | varia o primeiro | `pés de moleque` |
| repetição/onomatopeia | varia o segundo | `reco-recos` |
| segundo termo limita o primeiro | pode variar só o primeiro | `palavras-chave`, `salários-família` |

## Artigo

| Tipo | Formas | Uso |
| --- | --- | --- |
| definido | `o, a, os, as` | referente identificado/delimitado |
| indefinido | `um, uma, uns, umas` | referente não identificado ou apresentado |

- Artigo definido, indefinido e ausência de artigo podem mudar a referência.
- Contrações: `do = de + o`; `na = em + a`; `ao = a + o`.
- Artigo pode substantivar: `o não`, `um porquê`.

## Adjetivo

- Qualifica: `decisão justa`.
- Relaciona: `controle financeiro`.
- Uniforme: `servidor/servidora competente`.
- Biforme: `servidor atento` / `servidora atenta`.
- Gentílico: `maranhense`, `brasileiro`.
- Locução adjetiva: `amor de mãe`, `decisão de governo`.
- Substantivação: `o brasileiro` × `cidadão brasileiro`.

| Posição | Mudança frequente de sentido |
| --- | --- |
| `grande homem` / `homem grande` | notável / de grande porte |
| `velho amigo` / `amigo velho` | de longa data / idoso |
| `pobre homem` / `homem pobre` | digno de pena / sem recursos |
| `certo candidato` / `candidato certo` | algum / adequado |

### Compostos e grau

- Regra geral: varia o último elemento — `acordos luso-brasileiros`.
- Exceção tradicional: `surdos-mudos`.
- Cor com substantivo: frequentemente invariável — `camisas verde-oliva`.

| Grau | Modelo |
| --- | --- |
| comparativo de igualdade | `tão útil quanto` |
| superioridade/inferioridade | `mais/menos útil que` |
| sintético | `melhor`, `pior`, `maior`, `menor` |
| superlativo absoluto | `muito útil`, `utilíssimo` |
| superlativo relativo | `o mais útil` |

## Numeral

| Classe | Exemplos |
| --- | --- |
| cardinal | `um`, `dois`, `cem`, `mil` |
| ordinal | `primeiro`, `vigésima` |
| multiplicativo | `dobro`, `triplo` |
| fracionário | `meio`, `terço`, `quartos` |

- `duzentas páginas`; `primeira etapa`.
- `dois mil candidatos`, sem plural em `mil`.
- `dois milhões`, com plural em `milhão`.
- `ambos/ambas` = os dois/as duas, na classificação tradicional.

## Pronome

| Tipo | Exemplos e alerta |
| --- | --- |
| pessoal reto | `eu, tu, ele`; tipicamente sujeito |
| oblíquo átono | `me, te, o, a, lhe`; ligado ao verbo |
| oblíquo tônico | `mim, ti, si`; normalmente preposicionado |
| tratamento | 3ª pessoa: `Vossa Excelência decidiu` |
| possessivo | concorda com possuído: `minhas decisões` |
| demonstrativo | `este, esse, aquele`; também `o/a/os/as` em certos usos |
| relativo | `que, quem, cujo, onde, o qual` |
| indefinido | `alguém, ninguém, qualquer`; plural `quaisquer` |
| interrogativo | `que, quem, qual, quanto` |

- `para eu redigir`: `eu` é sujeito do infinitivo.
- `para mim`: `mim` não pratica a ação.
- `seu/sua` pode ser ambíguo; `de Pedro`, `dele/dela` pode esclarecer.
- Modelo tradicional: `este` pode anunciar; `esse` pode retomar.
- `isto, isso, aquilo` não variam nem acompanham substantivo expresso.
- Regência define preposição: `o assunto de que tratei`; `a pessoa a quem me referi`.
- `cujo` indica posse, concorda com o termo seguinte e não admite artigo: `cujas obras`.
- `onde` retoma lugar; em outros casos, use a forma relativa exigida pela regência.

## Roteiro de prova

1. Leia toda a oração.
2. Identifique o que a palavra faz: nomeia, determina, qualifica, quantifica, intensifica ou retoma.
3. Teste substituições: `o` = `ele` ou `aquilo`? `certo` = `algum` ou `correto`?
4. Diferencie classe, função e sentido.
5. Confira gênero, número, grau, pessoa e invariabilidade.
6. Em compostos, identifique a relação entre os elementos.
7. Em reescritas, preserve referência, posse, quantidade e efeito de posição.
8. Nos relativos, reconstrua a oração e aplique a regência.

## Pegadinhas finais

- `o/a` pode ser artigo, pronome pessoal ou demonstrativo.
- `que`, não o antecedente `o`, exerce função na oração relativa de `o que`.
- `todo país` ≠ `todo o país`.
- `bastantes recursos` ≠ `bastante atentos`.
- `meia hora` ≠ `meio cansada`.
- `mil` é invariável; `milhão` flexiona.
- `cujo` não aceita artigo.
- `onde` exige antecedente locativo.
